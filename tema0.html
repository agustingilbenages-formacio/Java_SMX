Què és programar?

La introducció motivadora del curs: què significa programar, quin idioma parlarem amb l'ordinador i el teu primer programa funcionant. Sense presses i sense por.

2 · Què aprendrem?

El que eixiràs sabent hui

  • Explicar què és programar i què és un programa, amb les teues paraules.
  • Distingir codi font, compilació i execució sense embolics.

3 · Teoria

Una idea, un exemple

3.1 · Un programa és una recepta

Un programa és una llista d'instruccions ordenades que l'ordinador executa una darrere d'altra. I un llenguatge de programació és l'idioma en què escrivim eixa llista: n'hi ha molts (Python, JavaScript, C#…), i nosaltres farem servir Java perquè és clar, establ i el trobaràs a tot arreu.

3.2 · Del paper a la pantalla: tres passos

  • Codi font: el que escrius tu en un fitxer de text, per exemple HolaMon.java.
  • Compilació: el programa javac tradueix el teu codi a l'idioma de la màquina. Si hi ha errades, t'ho diu ara.
  • Execució: el programa java posa en marxa el teu programa i veus el resultat.

3.3 · El teu primer programa

Este és el programa més famós del món: el «Hola món». Copia'l tal qual en un fitxer anomenat HolaMon.java:

HolaMon.java
public class HolaMon {
    public static void main(String[] args) {
        // La seua única faena: saludar per pantalla
        System.out.println("Hola món!");
    }
}
🧘 Tranquil·litat: això no cal entendre-ho encara

public class, static void i String[] args són paraules obligatòries perquè Java arranque. De moment no necessitem entendre esta part; ja arribarem més avant. Hui, l'únic important és la línia del mig: System.out.println(...) = «imprimeix això per pantalla i salta de línia».

3.4 · Executar i llegir errors sense por

A la terminal: javac HolaMon.java i després java HolaMon. Si tot va bé, veus «Hola món!». Si el compilador es queixa, llig l'error com un detectiu: quasi sempre diu el número de línia i què esperava trobar.

terminal
HolaMon.java:4: error: ';' expected
        System.out.println("Hola món!")
                                       ^
// Què ha passat? Falta el punt i coma del final.
// On? Línia 4. Ho arreglem i tornem a compilar.
4 · Programació guiada

Fem créixer el Hola Món, pas a pas

No copies el programa final: fes cada pas al teu editor, compila i executa abans de passar al següent. Si algo es trenca, perfecte: estás aprenent.

1

Canvia el missatge

Substituïx «Hola món!» pel teu nom i el teu grup. Compila i executa: el programa ara et saluda a tu.

System.out.println("Hola, sóc Alex i vaig a 1r de SMX!");
2

Més línies, més instruccions

Afig dos println més: un amb la teua assignatura preferida i un altre amb el teu menjar preferit. Mira l'ordre d'eixida: és el mateix ordre que el del codi?

System.out.println("M'agrada Informàtica.");
System.out.println("I la paella de la iaia.");
3

Dibuixa amb text

Amb println pots «dibuixar»: fes un robot o un cor amb caràcters. Compte amb les cometes dins del dibuix: si vols mostrar un ", escriu \".

System.out.println(" ----- ");
System.out.println("| o o |");
System.out.println("|  -  |");
System.out.println(" ----- ");
4

Trenca'l a propòsit

Borra un punt i coma, canvia println per printLn, deixa una cometa oberta… Compila cada error, llig el missatge i anota: què diu i en quina línia. Acabaràs sentint els errors com a pistes, no com a castigs.

5 · Errors habituals

Clàssics del Tema 0 (tots hi passen)

«';' expected»

Què ha passat:
falta el punt i coma al final d'una instrucció.
Per què:
en Java cada instrucció acaba en ;, sempre.
Com detectar-ho:
l'error marca la línia (a vegades l'anterior al problema).
Com corregir-ho:
posa el ; i compila de nou.

«cannot find symbol»

Què ha passat:
Java no reconeix una paraula, per exemple printLn.
Per què:
majúscules i minúscules importen: és println, tot minúscules.
Com detectar-ho:
el símbol que diu que no troba apareix entre cometes al missatge.
Com corregir-ho:
revisa majúscules/minúscules i errades de tecles.

El fitxer i la classe no coincideixen

Què ha passat:
class HolaMon dins d'un fitxer hola.java.
Per què:
el nom del fitxer ha de ser exactament el nom de la classe + .java.
Com detectar-ho:
error en compilar que parla de «class HolaMon is public».
Com corregir-ho:
canvia el nom del fitxer a HolaMon.java.

Executar sense compilar

Què ha passat:
«Error: no s'ha trobat o carregat la classe principal».
Per què:
Java no executa el .java: primer javac (compilar) i després java (executar).
Com detectar-ho:
no hi ha fitxer .class al costat del .java.
Com corregir-ho:
javac HolaMon.java i després java HolaMon (sense .class).

7 · Activitats

Tres sales d'entrenament

Mini exercicis (ràpids, a classe)

  1. Escriu el Hola Món de memòria (pots mirar el «tranquil·litat» per a les paraules rares).
  2. Fes que imprima tres línies: nom, edat i poble.
  3. Imprimeix el teu nom dins d'un marc de *.
  4. Canvia println per print en dues línies i explica la diferència.
  5. Provoca un error de punt i coma i copia ací el missatge exacte del compilador.
Pregunta 01

Un programa és…

Solució: B. Un programa no pensa: obeix, en ordre, la llista d'instruccions que algú ha escrit.
Pregunta 02

Quin programa tradueix el teu codi font a l'idioma de la màquina?

Solució: C. javac compila (tradueix); java executa el que ja està traduït.
Pregunta 03

Què fa System.out.println("Hola"); ?

Solució: A. El «ln» final vol dir «line»: imprimeix i salta de línia. Sense la ln, es queda en la mateixa línia.
Pregunta 04

En quin lloc comença a executar-se sempre un programa Java?

Solució: B. La porta d'entrada de tot programa Java és el main; sense ell, no arrenca.
Pregunta 05

Quin és l'ordre correcte per a vore el teu programa funcionant?

Solució: C. Primer el codi font, després la traducció i per últim l'execució. Sempre en eixe ordre.
Pregunta 06

El compilador es queixa amb «';' expected». Què li falta al teu codi?

Solució: A. Cada instrucció acaba en ;; és l'errada més comuna de les primeres setmanes.
Pregunta 07

Per què Java i no un altre llenguatge per a aprendre?

Solució: D. Java és estàndard de la indústria i el seu codi viatja a qualsevol sistema: perfecte per a aprendre fonaments sòlids.
Pregunta 08

El teu fitxer es diu Salut.java. Quin nom ha de tindre la classe dins?

Solució: B. Fitxer i classe han de coincidir lletra a lletra (majúscules incloses): Salut.java ↔ class Salut.
Pregunta 09

Veus un error roig en compilar. Quina és la millor primera reacció?

Solució: C. L'error és un missatge amb número de línia i pista: llegir-lo amb calma és la habilitat més professional que pots entrenar.
Exercici 1

La teua targeta de presentació

Fes un programa Presentacio.java que imprima, en quatre línies: el teu nom, la teua edat, el teu poble i què vols ser de major.

💡 Pista

Quatre System.out.println, un per línia. Recorda el punt i coma!

Presentacio.java
public class Presentacio {
    public static void main(String[] args) {
        System.out.println("Em dic Andrea.");
        System.out.println("Tinc 16 anys.");
        System.out.println("Sóc de Vila-real.");
        System.out.println("Vull ser desenvolupadora de videojocs.");
    }
}
Exercici 2

Art ASCII

Imprimeix per pantalla un dibuix fet amb caràcters (un coet, un cor, un robot…) d'almenys 5 línies.

💡 Pista

Si vols mostrar cometes dobles dins del text, escriu \". Les barres \ del dibuix també s'escriuen \\.

Coet.java
public class Coet {
    public static void main(String[] args) {
        System.out.println("   /\\");
        System.out.println("  /  \\");
        System.out.println(" |    |");
        System.out.println(" | oo |");
        System.out.println("/|    |\\");
        System.out.println(" '----'");
    }
}
Exercici 3

Caçador d'errors

Este programa té 3 errors. Copia'l, compila'l i arregla'ls un a un llegint els missatges:

Bugs.java (trencat a propòsit)
public class Bugs {
    public static void main(String[] args) {
        System.out.Println("Troba'm els errors!")
        system.out.println("Jo en trobe tres...");
    }
}
Bugs.java (arreglat)
public class Bugs {
    public static void main(String[] args) {
        // 1) println va tot en minúscules
        // 2) faltava el punt i coma
        // 3) System amb majúscula inicial
        System.out.println("Troba'm els errors!");
        System.out.println("Jo en trobe tres...");
    }
}
Repte 1

🤖 El robot de la cuina

Escriu en paper (i després en comentaris // dins d'un programa) les instruccions EXACTES perquè un robot faça un entrepà de tomàquet. Si una instrucció és ambigua («posa-li tomàquet»… quant? com?), el robot fallarà. Després, tradueix eixa llista a println que mostren cada pas per pantalla.

Repte 2

🎬 Crèdits de pel·lícula

Fes un programa que imprima els crèdits d'una pel·lícula inventada: títol gran amb caràcters, director, repartiment i «gràcies per vindre». Ha de tindre com a mínim 10 línies d'eixida i cap error de compilació.
