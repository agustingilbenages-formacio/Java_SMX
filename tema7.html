Un programa complet

Ja tens les peces: variables, decisions, bucles, arrays, mètodes i classes. Ara toca muntar-les totes juntes i construir, per primera vegada, un programa de veritat: amb menú, dades i vida pròpia.

⏱ 3 hores 🧩 Integrar tots els temes 📋 Planificar abans de programar 🔍 Provar i depurar

Material creat per Agustín Gil - IES La vereda 2026 · Llicència CC BY-NC 4.0

1 · Introducció

De trossets a programa

Un programa complet no és un exercici de 10 línies: és una aplicació amb menú que l'usuari fa servir, amb dades que es guarden mentre dura la sessió i amb diverses opcions. És el que fan les apps de l'institut, del banc o del videojoc… a la seua escala. I tu ja saps tot el que cal per a fer-ne una.

2 · Què aprendrem?

Objectius del tema

  • Planificar: dividir un problema gran en passos xicotets abans d'escriure codi.
  • Integrar tot el que hem aprés en un sol programa.
  • Construir un menú que no acabe mai (while + switch).
  • Provar a poc a poc: fer funcionar cada tros abans de continuar.
  • Depurar: trobar errors sense perdre els nervis.
3 · Teoria

Una idea, un exemple

3.1 · Primer es pensa, després es programa

El secret dels bons programadors no és escriure ràpid: és dividir el problema abans de teclejar. Quatre passos:

  1. Entén: què ha de fer exactament el programa? (Entrades, eixides.)
  2. Divideix: quins trossets xicotets el componen? (Afegir, cercar, mostrar…)
  3. Tria les eines: cada tros és un bucle? un mètode? una classe?
  4. Escriu i prova tros a tros, mai tot de colp.

3.2 · L'esquelet d'un programa amb menú

Gairebé totes les aplicacions de consola tenen esta forma: un bucle infinit amb un menú dins i una opció per a eixir.

Aplicacio.java
public class Aplicacio {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        boolean eixir = false;

        while (!eixir) {
            mostraMenu();
            int opcio = tec.nextInt();
            switch (opcio) {
                case 1: /* opció 1 */ break;
                case 2: /* opció 2 */ break;
                case 0: eixir = true;
                        System.out.println("Adéu! 👋"); break;
                default: System.out.println("Opció no vàlida");
            }
        }
    }

    public static void mostraMenu() {
        System.out.println("\n1 · Opció u");
        System.out.println("2 · Opció dos");
        System.out.println("0 · Eixir");
        System.out.print("Tria: ");
    }
}

3.3 · Les dades viuen fora del bucle

Mira què passa ací: si declares l'array DINS del bucle del menú, es buida a cada volta! Les dades del programa es declaren abans del bucle, perquè sobrevisquen entre opcions.

Dades.java
Llibre[] llibres = new Llibre[20];   // ACÍ, abans del bucle
int quantitat = 0;                    // quants en portem afegits

while (!eixir) {
    // les opcions del menú usen i modifiquen llibres i quantitat
}

3.4 · Provar com un professional

  • Casos de prova: pensa 3 situacions abans d'executar (dades normals, límits i dades rares).
  • Prova a poc a poc: cada funció nova, executada immediatament.
  • Imprimeix per a veure: un System.out.println a temps estalvia una hora de misteri.
  • Un error cada vegada: arregla'n un, torna a provar, i al següent.
4 · Programació guiada

El gestor de la biblioteca 📚

Un programa complet de veritat: guardar llibres, cercar-los, prestar-los i fer informes. Usa TOT: classes, arrays, bucles, decisions i mètodes.

1

La classe Llibre

Què guarda un llibre de la biblioteca? Títol, autor i exemplars disponibles.

public class Llibre {
    String titol;
    String autor;
    int exemplars;

    public void mostraFitxa() {
        System.out.println("«" + titol + "» de " + autor + " — " + exemplars + " exemplars");
    }
}
2

Les dades i el menú

Array de 20 llibres, comptador de quants n'hi ha, i el bucle del menú amb 4 opcions + eixir.

Llibre[] llibres = new Llibre[20];
int quantitat = 0;
// menú: 1 Afegir · 2 Llistar · 3 Cercar · 4 Prestar · 0 Eixir
3

Opció 1: afegir un llibre

Demana títol, autor i exemplars; crea l'objecte i guarda'l a la primera posició lliure. Què passa si l'array està ple?

case 1:
    if (quantitat < llibres.length) {
        Llibre nou = new Llibre();
        System.out.print("Títol: ");
        nou.titol = tec.nextLine();
        System.out.print("Autor: ");
        nou.autor = tec.nextLine();
        System.out.print("Exemplars: ");
        nou.exemplars = tec.nextInt();
        tec.nextLine();             // neteja el botó Intro pendent
        llibres[quantitat] = nou;
        quantitat++;
        System.out.println("Afegit! ✅");
    } else {
        System.out.println("La biblioteca està plena!");
    }
    break;

El tec.nextLine() extra després de nextInt() és un truc: quan barreges números i text, cal «netejar» el teclat. De moment no necessitem entendre esta part; ja arribarem més avant.

4

Opcions 2 i 3: llistar i cercar

Llistar: un for fins a quantitat cridant mostraFitxa(). Cercar: demana un títol i recorr l'array comparant amb .equals().

// cercar
boolean trobat = false;
for (int i = 0; i < quantitat; i++) {
    if (llibres[i].titol.equals(buscat)) {
        llibres[i].mostraFitxa();
        trobat = true;
    }
}
if (!trobat) System.out.println("No el tenim 😕");
5

Opció 4: prestar i informe final

Prestar = cercar el llibre i restar un exemplar (si en queden!). I en eixir: informe amb total de llibres, total d'exemplars i el llibre amb més exemplars.

// prestar (dins del if de trobat):
if (llibres[i].exemplars > 0) {
    llibres[i].exemplars--;
    System.out.println("Prestat! Bona lectura 📖");
} else {
    System.out.println("No en queden exemplars!");
}
5 · Errors habituals

Errors de programa gran

Programar sense pla

Què:
200 línies de codi que no fan el que volies.
Per què:
has començat a teclejar sense dividir el problema.
Detectar-ho:
no saps per on continuar.
Corregir-ho:
escriu els passos en paper ABANS de programar.

Les dades es borren soles

Què:
afigs un llibre i en tornar al menú ja no hi és.
Per què:
has declarat les dades dins del bucle.
Detectar-ho:
funciona dins de l'opció i desapareix després.
Corregir-ho:
dades ABANS del while.

nextInt() es menja l'Intro

Què:
després d'un número, el nextLine() torna buit.
Per què:
queda un salt de línia pendent al teclat.
Detectar-ho:
els textos es salten «sols».
Corregir-ho:
un tec.nextLine() extra després del número.

Tot dins del main

Què:
un main de 300 línies impossible de seguir.
Per què:
no has usat mètodes ni classes.
Detectar-ho:
has de fer scroll per a trobar res.
Corregir-ho:
cada tasca, el seu mètode.
6 · Resum visual

Idees que es queden

🧠Pensa i divideix ANTES de programar.
🔁Menú = while + switch + opció 0 per a eixir.
📦Les dades viuen abans del bucle.
🧩Cada tasca en el seu mètode; cada cosa real, en la seua classe.
🔍Prova cada tros abans de continuar.
🐛Un error cada vegada: repara, prova, continua.

Pregunta 01

Abans d'escriure un programa complet, el primer pas és…

Solució: C. Primer es pensa, després es programa. El pla en paper estalvia hores de codi.
Pregunta 02

Un menú que es repeteix fins que l'usuari trie «eixir» es fa amb…

Solució: A. El while manté l'app viva; el switch reparteix cada opció.
Pregunta 03

Les dades del programa (arrays, comptadors) s'han de declarar…

Solució: B. Si les declares dins del bucle, es creen de nou (i es buiden) a cada volta.
Pregunta 04

Per a provar un programa com cal, el millor és…

Solució: D. Provar a poc a poc: un error trobat prompte és barat; trobat al final, caríssim.
Pregunta 05

El programa fa algo rar i no saps per què. Què fas primer?

Solució: A. Depurar = observar. Els prints (o el depurador de l'IDE) mostren què passa de veritat.
Pregunta 06

En un programa amb classes, el main hauria de…

Solució: C. El main és el cap d'obra: reparteix la faena, no la fa tota.
Pregunta 07

Un «cas de prova» és…

Solució: B. «Si pose nota 0, què hauria de passar?» — això és un cas de prova.
Pregunta 08

Què imprimeix?

int opcio = 5;
switch (opcio) {
    case 1: System.out.println("Un"); break;
    case 2: System.out.println("Dos"); break;
    default: System.out.println("Altre");
}
Solució: D. Cap case coincideix amb 5, així que entra pel default: per això cal posar-lo sempre.
Pregunta 09

Acabes el programa. Últim pas abans de donar-lo per bo…

Solució: A. I si l'usuari posa una altra cosa? Els programes robustos sobreviuen a les dades rares.
Pregunta 10

En un programa complet ben organitzat, el main hauria de ser…

Solució: B. El main és el cap d'obra: organitza i reparteix. La faena de veritat viu en mètodes i classes.
Exercici 1

El joc complet: Endevina el número PRO 🎯

El joc del tema 3, ara com a programa amb menú: 1 jugar, 2 veure rècord, 0 eixir. Guarda la millor partida (menys intents) i mostra-la. Divídeix-lo en mètodes.

EndevinaPro.java
import java.util.Random;
import java.util.Scanner;

public class EndevinaPro {
    static Scanner tec = new Scanner(System.in);
    static int record = 0;          // 0 = encara no hi ha rècord

    public static void main(String[] args) {
        boolean eixir = false;
        while (!eixir) {
            System.out.println("\n1 · Jugar");
            System.out.println("2 · Veure rècord");
            System.out.println("0 · Eixir");
            System.out.print("Tria: ");
            int opcio = tec.nextInt();
            switch (opcio) {
                case 1: jugar(); break;
                case 2: veureRecord(); break;
                case 0: eixir = true; System.out.println("Adéu!"); break;
                default: System.out.println("Opció no vàlida");
            }
        }
    }

    public static void jugar() {
        Random atzar = new Random();
        int secret = atzar.nextInt(100) + 1;
        int intent = 0, voltes = 0;
        while (intent != secret) {
            System.out.print("Número (1-100): ");
            intent = tec.nextInt();
            voltes++;
            if (intent < secret) System.out.println("Més alt!");
            else if (intent > secret) System.out.println("Més baix!");
        }
        System.out.println("Encertat en " + voltes + " intents!");
        if (record == 0 || voltes < record) {
            record = voltes;
            System.out.println("Nou rècord! 🏆");
        }
    }

    public static void veureRecord() {
        if (record == 0) System.out.println("Encara no has jugat!");
        else System.out.println("Rècord: " + record + " intents");
    }
}
Exercici 2

Gestor de notes de la classe 📝

Menú: 1 afegir alumne amb nota, 2 llistar tots, 3 mitjana de la classe, 4 millor nota (amb nom), 0 eixir. Usa un array d'alumnes (nom + nota) i un comptador.

GestorNotes.java
import java.util.Scanner;

public class GestorNotes {
    static Scanner tec = new Scanner(System.in);
    static String[] noms = new String[30];
    static double[] notes = new double[30];
    static int quantitat = 0;

    public static void main(String[] args) {
        boolean eixir = false;
        while (!eixir) {
            System.out.println("\n1 · Afegir alumne");
            System.out.println("2 · Llistar");
            System.out.println("3 · Mitjana");
            System.out.println("4 · Millor nota");
            System.out.println("0 · Eixir");
            System.out.print("Tria: ");
            int opcio = tec.nextInt();
            tec.nextLine();
            switch (opcio) {
                case 1: afegir(); break;
                case 2: llistar(); break;
                case 3: mitjana(); break;
                case 4: millor(); break;
                case 0: eixir = true; break;
                default: System.out.println("Opció no vàlida");
            }
        }
    }

    public static void afegir() {
        if (quantitat >= noms.length) { System.out.println("Ple!"); return; }
        System.out.print("Nom: ");
        noms[quantitat] = tec.nextLine();
        System.out.print("Nota (0-10): ");
        notes[quantitat] = tec.nextDouble();
        quantitat++;
    }

    public static void llistar() {
        for (int i = 0; i < quantitat; i++) {
            System.out.println(noms[i] + " — " + notes[i]);
        }
    }

    public static void mitjana() {
        if (quantitat == 0) { System.out.println("No hi ha alumnes!"); return; }
        double total = 0;
        for (int i = 0; i < quantitat; i++) total += notes[i];
        System.out.println("Mitjana: " + (total / quantitat));
    }

    public static void millor() {
        if (quantitat == 0) { System.out.println("No hi ha alumnes!"); return; }
        int pos = 0;
        for (int i = 1; i < quantitat; i++) {
            if (notes[i] > notes[pos]) pos = i;
        }
        System.out.println("Millor: " + noms[pos] + " amb " + notes[pos]);
    }
}
Exercici 3

El banc senzill 🏦

Programa amb menú per a gestionar un compte: 1 consultar saldo, 2 ingressar, 3 retirar, 4 veure últims 5 moviments, 0 eixir. Guarda els moviments en un array i valida les quantitats (no negatives, no retirar més del saldo).

Banc.java
import java.util.Scanner;

public class Banc {
    static Scanner tec = new Scanner(System.in);
    static double saldo = 0;
    static double[] moviments = new double[100];
    static String[] conceptes = new String[100];
    static int quantitat = 0;

    public static void main(String[] args) {
        boolean eixir = false;
        while (!eixir) {
            System.out.println("\nSaldo actual: " + saldo + " €");
            System.out.println("1 · Ingressar");
            System.out.println("2 · Retirar");
            System.out.println("3 · Últims moviments");
            System.out.println("0 · Eixir");
            System.out.print("Tria: ");
            int opcio = tec.nextInt();
            switch (opcio) {
                case 1: mou("Ingrés", true); break;
                case 2: mou("Reintegrament", false); break;
                case 3: historial(); break;
                case 0: eixir = true; break;
                default: System.out.println("Opció no vàlida");
            }
        }
    }

    public static void mou(String concepte, boolean esIngres) {
        System.out.print("Quantitat: ");
        double q = tec.nextDouble();
        if (q <= 0) { System.out.println("Quantitat no vàlida!"); return; }
        if (!esIngres && q > saldo) { System.out.println("Saldo insuficient!"); return; }
        saldo = esIngres ? saldo + q : saldo - q;
        moviments[quantitat] = esIngres ? q : -q;
        conceptes[quantitat] = concepte;
        quantitat++;
        System.out.println("Fet! Nou saldo: " + saldo + " €");
    }

    public static void historial() {
        int inici = quantitat - 5;
        if (inici < 0) inici = 0;
        for (int i = inici; i < quantitat; i++) {
            System.out.println(conceptes[i] + ": " + moviments[i] + " €");
        }
    }
}
Exercici 4

La llista de la compra 🛍️

Programa complet amb menú: afegir producte amb preu, llistar tot, mostrar el total i dir quin és el més car. Usa dos arrays paral·lels (noms i preus), un comptador i un mètode per a cada opció.

LlistaCompra.java
import java.util.Scanner;

public class LlistaCompra {
    static Scanner tec = new Scanner(System.in);
    static String[] noms = new String[20];
    static double[] preus = new double[20];
    static int quantitat = 0;

    public static void main(String[] args) {
        boolean eixir = false;
        while (!eixir) {
            System.out.println("\n1 · Afegir producte");
            System.out.println("2 · Llistar");
            System.out.println("3 · Total");
            System.out.println("4 · El més car");
            System.out.println("0 · Eixir");
            System.out.print("Tria: ");
            int opcio = tec.nextInt();
            switch (opcio) {
                case 1: afegir(); break;
                case 2: llistar(); break;
                case 3: total(); break;
                case 4: mesCar(); break;
                case 0: eixir = true; break;
                default: System.out.println("Opció no vàlida");
            }
        }
    }

    public static void afegir() {
        if (quantitat >= noms.length) {
            System.out.println("La llista està plena!");
            return;
        }
        tec.nextLine();
        System.out.print("Producte: ");
        noms[quantitat] = tec.nextLine();
        System.out.print("Preu: ");
        preus[quantitat] = tec.nextDouble();
        quantitat++;
    }

    public static void llistar() {
        for (int i = 0; i < quantitat; i++) {
            System.out.println(noms[i] + " — " + preus[i] + " €");
        }
    }

    public static void total() {
        double suma = 0;
        for (int i = 0; i < quantitat; i++) {
            suma += preus[i];
        }
        System.out.println("Total: " + suma + " €");
    }

    public static void mesCar() {
        if (quantitat == 0) {
            System.out.println("No hi ha productes!");
            return;
        }
        int pos = 0;
        for (int i = 1; i < quantitat; i++) {
            if (preus[i] > preus[pos]) pos = i;
        }
        System.out.println("El més car: " + noms[pos] + " (" + preus[pos] + " €)");
    }
}
