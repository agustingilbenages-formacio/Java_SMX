01
Primera hora

Introducció i fonaments

Abans de picar codi, cal saber on ens meterem. Java és com el valencià de la informàtica: el parlen a tot arreu i qui el domina té mig camí fet.

1.1 · Per què Java?

  • «Escriu-ho una vegada, executa-ho a tot arreu»: el teu codi es converteix en bytecode i qualsevol màquina amb una JVM el fa córrer (Windows, macOS, Linux, Android…).
  • Estàndard de la indústria: banca, grans empreses, servidors i Android. Hi ha milions de llocs de treball que el demanen.
  • Ecosistema enorme: llibreries per a tot, documentació oficial i respostes a qualsevol dubte en dos minuts.
  • Et fa escriure bé: la seua sintaxi estricta t'obliga a ordenar el cap; després, passar a C#, Kotlin o JavaScript és molt més fàcil.
  • Gratuït i estable: versions LTS (Long Term Support) amb anys de suport, com la 21 que farem servir.

1.2 · El teu primer programa

Tot programa Java viu dins d'una classe i arrenca pel mètode main. Memoritza esta estructura, perquè la escriuràs mil vegades:

HolaMon.java
public class HolaMon {
    public static void main(String[] args) {
        // El meu primer programa en Java
        System.out.println("Hola, món! Ja programe en Java!");
    }
}

A la terminal, dos passos: javac HolaMon.java (compila i genera el .class) i java HolaMon (executa). Si veus el missatge a pantalla… ja eres programador o programadora. 🎉

🧰 Abans de començar a classe
  • Instal·la el JDK 21 LTS des d'adoptium.net i comprova-ho amb java -version.
  • Baixa't un editor seriós: VS Code o IntelliJ IDEA Community (gratuïts).
  • Aprén a obrir la terminal: compilar a mà t'ensenya què fa l'IDE per darrere.

1.3 · Variables i tipus de dades

Una variable és una capsa amb etiqueta on guardem una dada. En Java cal dir sempre quin tipus de dada hi cabrà dins: això es diu que és un llenguatge fortament tipat.

1.4 · Regles d'or de la sintaxi

  • Punt i coma al final de cada instrucció. Si l'oblides, l'error pot aparéixer línies més avall: no et fies del número de línia!
  • Majúscules i minúscules importen: Edat, edat i EDAT són tres variables diferents.
  • camelCase per a variables i mètodes (notaFinal), PascalCase per a classes (HolaMon).
  • Comentaris: // línia i /* bloc */. Comentar el «perquè», no l'obvi.
  • Les claus { } delimiten blocs: classe, mètode, condició, bucle. Indenta sempre: el codi es llig més del que s'escriu.

1.5 · Entrades i eixides

Per a parlar amb l'usuari usem System.out.println (imprimeix i salta línia), print (sense salt) i printf (formatat). Per a llegir del teclat, la classe Scanner:

DemanaNom.java
import java.util.Scanner;

public class DemanaNom {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);

        System.out.print("Com et diuges? ");
        String nom = tec.nextLine();       // llig una línia de text

        System.out.println("Bon dia, " + nom + "!");
    }
}

Segona hora · part 1

Estructures de control

Fins ara el codi sempre fa el mateix. Les estructures de control li donen criteri (decidir) i resistència (repetir). Dos poders, quatre paraules clau.

2.1 · Condicionals: if / else

La idea és la de tota la vida: si passa això, fes això; si no, fes allò altre. La condició va entre parèntesis i sempre dona true o false.

Notes.java
int nota = 7;

if (nota >= 9) {
    System.out.println("Excel·lent!");
} else if (nota >= 5) {
    System.out.println("Aprovat: continua així!");
} else {
    System.out.println("Suspés: ho repassarem junts.");
}

2.2 · switch: quan hi ha moltes opcions

Si comparesres una variable contra molts valors concrets, el switch és més net que una escala d'if. Des de Java 14 tenim la versió moderna amb fletxes ->, que ja no necessita break:

Grups.java
char grup = 'B';

switch (grup) {
    case 'A' -> System.out.println("Aula 1.01");
    case 'B' -> System.out.println("Aula 1.02");
    case 'C' -> System.out.println("Aula 2.01");
    default  -> System.out.println("Grup no reconegut");
}

També tens l'operador ternari, un «if de butxaca» per a assignacions curtes: String missatge = (nota >= 5) ? "Aprovat" : "Suspés";

2.3 · El bucle for

El for repeteix un bloc un nombre controlat de vegades. Té tres peces entre parèntesis: inicialització, condició i actualització.

Voltes.java
for (int i = 1; i <= 5; i++) {
    System.out.println("Volta número " + i);
}

2.4 · while i do-while

Quan no saps quantes voltes faràs (esperar fins que l'usuari encerte, per exemple), usem while: repeteix mentre la condició siga certa. El do-while és el germà que executa el cos almenys una vegada i després pregunta.

Vides.java
int vida = 3;

while (vida > 0) {
    System.out.println("Vides restants: " + vida);
    vida--;                  // sense això: bucle infinit!
}
System.out.println("Fi del joc");

Dins d'un bucle, break ix immediatament i continue salta a la següent volta.

2.5 · El patró que ho arregla (gairebé) tot: comptador i acumulador

Gauss.java
int suma = 0;                     // l'acumulador comença a zero
for (int i = 1; i <= 100; i++) {
    suma += i;                    // suma = suma + i
}
System.out.println("1+2+...+100 = " + suma);   // 5050
🚨 Errors típics del principi (tots hi hem caigut)
  • Confondre = (assignar) amb == (comparar).
  • Posar un ; just després del for o de l'if: el bloc queda despenjat.
  • Oblidar actualitzar la variable del while → bucle infinit.
  • En el switch clàssic, oblidar el break i «caure» al cas següent.
🔮 Prediu l'eixida #2
for (int i = 0; i < 5; i++) {
    if (i == 3) continue;
    System.out.print(i + " ");
}

Segona hora · part 2

Estructures de dades i modularitat

Guardar una dada està bé; guardar-ne mil i saber-les manejar és una altra lliga. I si a més trocegem el programa en peces reutilitzables, ja parlem com a professionals.

3.1 · Arrays: una fila de capses del mateix tipus

Un array guarda molts valors del mateix tipus en posicions numerades. Ull: la primera posició és la 0, i la mida és fixa: si en crees un de 5, tindrà 5 posicions tota la vida.

Recorregut.java
int[] notes = {8, 6, 9, 5, 7};

System.out.println(notes[0]);        // 8: el primer!
System.out.println(notes.length);    // 5

for (int i = 0; i < notes.length; i++) {
    System.out.println("Posició " + i + ": " + notes[i]);
}

for (int n : notes) {                // for-each: quan no cal l'índex
    System.out.println(n);
}

Si demanes una posició que no existeix, Java et llança una ArrayIndexOutOfBoundsException: l'error més famós de la història del curs. 😅 Amb dues dimensions, int[][] tauler = new int[3][3]; és una taula: tauler[fila][columna].

I la pinzellada pro: ArrayList és un array que creix i s'encongeix sol (add, remove, size, get). Quan no sàpies la mida d'entrada, és la teua amiga.

3.2 · Mètodes: trocejar per a vèncer

Un mètode és un bloc de codi amb nom que fa una faena concreta. Rep dades per paràmetres i pot tornar un resultat amb return. Regla del departament: un mètode, una faena; si necessites un «i» per a explicar què fa, parteix-lo en dos.

Calculadora.java
public class Calculadora {
    public static void main(String[] args) {
        System.out.println("3 + 4 = " + suma(3, 4));
        System.out.println("Mitjana: " + mitjana(8, 6, 9));
    }

    static int suma(int a, int b) {          // torna un int
        return a + b;
    }

    static double mitjana(double a, double b, double c) {
        return (a + b + c) / 3;              // torna un double
    }
}
  • Signatura = què rep i què torna: static int suma(int a, int b).
  • void significa «no torna res»: només fa (imprimir, guardar…).
  • Les variables creades dins d'un mètode moren en eixir: és l'àmbit local.
  • Sobrecàrrega: pots tenir dos mètodes amb el mateix nom si canvien els paràmetres.
🔮 Prediu l'eixida #3
static int doble(int n)  { return n * 2; }
static int suma(int a, int b) { return a + b; }

// al main:
System.out.println(doble(3) + suma(1, 2));

Tercera hora

Una pinzellada de POO i IA

Rematem la masterclass amb les dues idees que més es comenten al pati: la programació orientada a objectes i la IA que ja s'asseu al nostre costat a classe.

4.1 · Classe i objecte, explicat per a tothom

Una classe és el plànol; un objecte és la casa construïda seguint-lo. El plànol no pots habitar-lo, però et deixa fer totes les cases iguals que vulgues. En Java, la classe defineix atributs (el que l'objecte té) i mètodes (el que l'objecte sap fer), i amb la paraula new fabriquem objectes.

Cotxe.java
public class Cotxe {
    String marca;              // atributs: el que TÉ
    int velocitat;

    Cotxe(String marca) {      // constructor: s'executa amb new
        this.marca = marca;
        this.velocitat = 0;
    }

    void accelerar(int quant) {          // mètodes: el que SAP FER
        this.velocitat += quant;
    }

    String presentarse() {
        return marca + " a " + velocitat + " km/h";
    }
}

// Al main:
Cotxe meu = new Cotxe("Seat");     // un OBJECTE
Cotxe teu = new Cotxe("Tesla");    // un altre OBJECTE
meu.accelerar(50);
System.out.println(meu.presentarse());   // "Seat a 50 km/h"

Amb això ja en tens prou per a entendre el 80% del que veuràs. Si un dia et parlen d'herència (una classe filla que aprofita el codi de la mare) o de polimorfisme (tractar objectes diferents per la mateixa interfície), ja saps que existeixen: el resto és qüestió de pràctica.

4.2 · La IA ja s'asseu a la teua taula

Eines com GitHub Copilot, ChatGPT, Claude o Gemini ja escriuen codi Java: t'expliquen un error en valencià si els ho demanes, et generen l'esquelet d'un exercici, et converteixen pseudocodi en Java i et proposen tests. Però vaig a ser clar amb tu: la IA és un copilot, no el pilot. Si copies sense entendre, el dia de l'examen el copilot no entra a l'aula.

Prompt pobre 😴Prompt pro 🚀
«Fes-me l'exercici»«Tinc un array de notes en Java; vull un mètode que torne la mitjana. Explica'm cada línia com si fóra la primera vegada que la veig.»
«No em funciona»«Este codi llança ArrayIndexOutOfBoundsException a la línia 12. Enganxe el codi i l'error complet. Per què passa i com ho evite?»
«Escriu-me un bucle»«Necessite recórrer un array de 10 enters i comptar quants són parells, amb un for i un if. Dona'm el codi i dos pistes per a fer-lo jo després.»
🧠 Les 5 regles d'or de la IA a classe
  • Entén-ho abans de copiar-ho: si no ho saps explicar, no és teu.
  • La IA s'equivoca (i amb molta seguretat): contrasta sempre executant.
  • Dona-li context: enuncia't, el teu codi actual i l'error exacte.
  • Demana pistes, no solucions: «guia'm sense donar-me el codi sencer».
  • A l'examen, tu a soles: entrena sense copilot des del primer dia.

Taller final

Pràctiques: ara et toca a tu

Tres sales d'entrenament. Passa per les tres en ordre: primer comprova que ho has entés, després pica codi de veres i, per últim, crema't el cap amb els reptes.

Nou preguntes sense trampa ni cartó: llig-les, tria la teua resposta mentalment (o marcant-la) i després prem «Mostrar solució» per a comprovar. Cap nota ací: equivocar-se ací és gratis, a l'examen no. 😉

Pregunta 01

Quin tipus de dada és el més adequat per a guardar l'edat d'una persona?

Solució: B. L'edat és un número enter i curtet: int és exactament el seu lloc. double seria per a decimals i char per a un sol caràcter.
Pregunta 02

Quin és l'índex del primer element d'un array en Java?

Solució: A. En Java (i en quasi tots els llenguatges) es compta des de zero: notes[0] és el primer element.
Pregunta 03

Quina paraula clau repetix un bloc de codi mentre la condició siga certa?

Solució: C. while (condicio) repetix el bloc mentre la condició es complisca; switch és per a decidir, no per a repetir.
Pregunta 04

Què imprimeix System.out.println(7 / 2); ?

Solució: B. Entre enters, Java fa divisió entera i descarta els decimals: 7 / 2 = 3. Per a obtindre 3.5 caldria que algun operand fóra decimal (7.0 / 2).
Pregunta 05

En un switch clàssic (amb case:), què passa si oblidem el break?

Solució: C. És el famós fall-through: sense break, l'execució continua pels casos de baix encara que no coincidisquen. Per això la versió moderna amb -> és tan còmoda.
Pregunta 06

Quina és la signatura correcta d'un mètode que rep dos enters i en torna un altre?

Solució: C. Ha d'indicar el tipus que torna (int, no void) i el tipus de cada paràmetre (int a, int b, mai sense tipus).
Pregunta 07

Què imprimeix este codi? int[] notes = new int[3]; System.out.println(notes[1]);

Solució: B. Java inicialitza sol els arrays numèrics a 0 (els boolean a false, etc.). No hi ha «brossa» en memòria com en altres llenguatges.
Pregunta 08

Què imprimeix este codi? char c = 'A'; System.out.println(c + 1);

Solució: C. Un char és un número per dins ('A' val 65 en la taula Unicode). En sumar-hi 1, Java el tracta com a enter i imprimeix 66. Per a vore «B» caldria convertir: (char)(c + 1).
Pregunta 09

Què imprimeix este bucle?

int total = 0;
for (int i = 1; i <= 4; i++) {
    if (i % 2 == 0) {
        total += i;
    }
}
System.out.println(total);
Solució: B. Només se sumen els parells de l'1 al 4: 2 + 4 = 6. El i % 2 == 0 és el filtre que deixa passar els parells.

Set programes curts per a picar a classe o a casa. Intenta'ls primer sense mirar res: si et bloqueges, tens una pista plegable i, al final, la solució completa llesta per a comparar.

Exercici 1 · Nivell calentament

El salutador educat

Deman a l'usuari el seu nom i el seu any de naixement amb un Scanner, i imprimeix: «Bon dia, NOM! L'any que ve faràs EDAT anys.» (pista: estem en 2026).

💡 Pista

Llig l'any amb tec.nextInt() i calcula 2027 - any. Vigila: després de nextInt(), si lliges text, cal consumir el salt de línia.

Salutador.java
import java.util.Scanner;

public class Salutador {
    public static void main(String[] args) {

        System.out.print("Com et diuges? ");
        String nom = tec.nextLine();

        System.out.print("En quin any vas nàixer? ");
        int any = tec.nextInt();

        int edatQueVe = 2027 - any;
        System.out.println("Bon dia, " + nom + "! L'any que ve faràs "
                           + edatQueVe + " anys.");
    }
}
Exercici 2 · Condicionals

La mitjana que aprova

Llig tres notes (decimals) i mostra la mitjana amb un decimal. Si és 5 o més, «Aprovat 🎉»; si no, «A recuperar-se 💪».

💡 Pista

Per a imprimir amb un decimal pots usar System.out.printf("Mitjana: %.1f%n", mitjana);.

Mitjana.java
import java.util.Scanner;

public class Mitjana {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        double suma = 0;

        for (int i = 1; i <= 3; i++) {
            System.out.print("Nota " + i + ": ");
            suma += tec.nextDouble();
        }

        double mitjana = suma / 3;
        System.out.printf("Mitjana: %.1f%n", mitjana);

        if (mitjana >= 5) {
            System.out.println("Aprovat!");
        } else {
            System.out.println("A recuperar-se!");
        }
    }
}
Exercici 3 · Bucles

La taula de multiplicar

Demana un número enter i imprimeix la seua taula de multiplicar de l'1 al 10 amb un for, amb el format 7 x 3 = 21.

💡 Pista

Dins del bucle necessites la variable de volta i i el número triat: num + " x " + i + " = " + (num * i).

import java.util.Scanner;

public class Taula {

Exercici 4 · while + aleatoris

Endevina el número

L'ordinador pensa un número de l'1 al 100 (new Random().nextInt(100) + 1) i l'usuari l'ha d'endevinar. A cada intent, el programa dirà «més alt» o «més baix», i en encertar mostrarà quants intents ha calgut.

💡 Pista

Un while (intent != secret) amb un comptador d'intents que creix a cada volta.

Endevina.java
import java.util.Random;
import java.util.Scanner;

public class Endevina {
    public static void main(String[] args) {
        Random atzar = new Random();
        Scanner tec = new Scanner(System.in);

        int secret = atzar.nextInt(100) + 1;
        int intent = 0, voltes = 0;

        while (intent != secret) {
            System.out.print("Quin número pense? ");
            intent = tec.nextInt();
            voltes++;

            if (intent < secret)      System.out.println("Més alt!");
            else if (intent > secret) System.out.println("Més baix!");
        }
        System.out.println("Enhorabona! L'has encertat en "
                           + voltes + " intents.");
    }
}
Exercici 5 · Cadenes i bucles

El comptador de vocals

Demana una frase i compta quantes vocals té (majúscules i minúscules). Recorre-la amb charAt(i) i un bucle.

💡 Pista

Converteix tota la frase a minúscules amb frase.toLowerCase() i compara cada caràcter contra "aeiou".

Vocals.java
import java.util.Scanner;

public class Vocals {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        System.out.print("Escriu una frase: ");
        String frase = tec.nextLine().toLowerCase();

        int comptador = 0;
        for (int i = 0; i < frase.length(); i++) {
            char c = frase.charAt(i);
            if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
                comptador++;
            }
        }
        System.out.println("La frase té " + comptador + " vocals.");
    }
}
Exercici 6 · Mètodes

Cribrant nombres primers

Crea un mètode static boolean esPrimer(int n) i usa'l des del main per a imprimir tots els primers entre 2 i 50.

💡 Pista

Dins d'esPrimer, prova a dividir n entre 2 i n-1 (o fins a n/2): si alguna divisió és exacta, no és primer.

Primers.java
public class Primers {
    public static void main(String[] args) {
        System.out.println("Primers fins a 50:");
        for (int n = 2; n <= 50; n++) {
            if (esPrimer(n)) {
                System.out.print(n + " ");
            }
        }
    }

    static boolean esPrimer(int n) {
        for (int d = 2; d <= n / 2; d++) {
            if (n % d == 0) return false;   // divisible: no és primer
        }
        return true;
    }
}
Exercici 7 · POO

La classe Alumne

Crea la classe Alumne amb els atributs nom i nota, un constructor i un mètode presentarse() que torne un text. Al main, crea un array de 3 alumnes i mostra la presentació de cadascun.

💡 Pista

Alumne[] classe = new Alumne[3]; i després classe[0] = new Alumne("Marina", 8.5); etc.

Alumne.java
public class Alumne {
    String nom;
    double nota;

    Alumne(String nom, double nota) {
        this.nom = nom;
        this.nota = nota;
    }

    String presentarse() {
        return "Sóc " + nom + " i tinc un " + nota;
    }

    public static void main(String[] args) {
        Alumne[] classe = new Alumne[3];
        classe[0] = new Alumne("Marina", 8.5);
        classe[1] = new Alumne("Pau", 6.25);
        classe[2] = new Alumne("Aitana", 9.75);

        for (Alumne a : classe) {
            System.out.println(a.presentarse());
        }
    }
}

Repte 1 · Vida real

📚 Gestor de notes de la classe

El teu tutor vol un programa per a gestionar les notes d'avaluació de la classe de SMX. Ha de demanar quantes notes vol introduir (màxim 30), guardar-les en un array i oferir un menú: 1) mostrar totes, 2) mitjana, 3) nota més alta, 4) quantes hi ha suspeses, 0) eixir.

  • Valida que les notes estiguen entre 0 i 10.
  • El menú ha de repetir-se fins que es trie eixir.
  • Fes un mètode per a cada opció del menú.
Repte 2 · Vida real

🏧 El caixer que mai no es queda sense paciència

Simula un caixer automàtic: demana un PIN (correcte: 1234) amb tres intents màxims. Una volta dins, el saldo inicial és 100 € i l'usuari pot ingressar, retirar (mai més del que hi haja) i consultar saldo, fins que trie eixir. Mostra un «ticket» amb tots els moviments al final.

  • Tres intents de PIN: al tercer fallit, el programa acaba.
  • Un retir no pot deixar el saldo en negatiu.
  • Guarda els moviments en dos arrays paral·lels (tipus i quantitat).
Repte 3 · Vida real

🎯 El penjat de la sobretaula

Implementa el joc del penjat: el programa tria una paraula secreta d'un array de paraules (per exemple, termes d'informàtica) i l'usuari diu lletres. Mostra els encerts com a guionets (- - - -), les lletres fallades i els intents restants (6). Guanya qui completa la paraula; perd qui esgota els intents.

  • Un array de char o de boolean per a les lletres descobertes.
  • Controla que no es repetisca una lletra ja dita.
  • Bonus: dibuixa el penjat per pantalla amb caràcters ASCII.
Repte 4 · Vida real

📇 L'agenda del delegat

El delegat de classe vol una agenda de contactes: nom i telèfon. El programa ha de permetre afegir contactes (màxim 50), buscar per nom (mostrant el telèfon), llistar tots ordenats alfabèticament i esborrar-ne un. Quan busques o esborres, si el nom no existeix, missatge amable.

  • Dos arrays paral·lels o un ArrayList: tria tu i justifica-ho.
  • Per a ordenar, pots investigar Arrays.sort()… però compte amb els arrays paral·lels!
  • Ignora majúscules/minúscules en les cerques (equalsIgnoreCase).
Repte 5 · Vida real + POO

🛒 La tendeta del barri, en Java

Crea la classe Producte (nom, preu sense IVA, estoc) amb els seus mètodes. Al main, munta una tendeta amb 5 productes: mostra el catàleg, demana quantes unitats vol el client de cada un i imprimeix el ticket final amb IVA (21%) i total. Si no hi ha estoc suficient, avisa i ven només el que hi haja.

  • Mètode double preuAmbIva() a la classe.
  • Mètode boolean potVendre(int unitats) que consulte l'estoc.
  • El ticket ha de mostrar línia a línia: nom, unitats, import.
Repte 6 · Meta-repte

🤖 Intercanvi de papers amb la IA

Ara qui programa és l'altre: escriu un enunciat d'exercici de Java (com els d'esta pàgina) i demana-li a una IA que el resolga. Després, amb el teu criteri de futur desenvolupador, avalua la seua solució: compila? Fa el que demanava l'enunciat? L'explicació és correcta? Anota tres errors o millores que li detectes.

  • Si no li trobes ni una pega… sospeita i prova el codi amb més casos.
  • Compara la solució de dues IA diferents: no sempre diuen el mateix!
  • Acaba reescrivint tu la versió definitiva, sense mirar cap de les dues.
