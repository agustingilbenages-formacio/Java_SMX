Variables: guardar informació

Un videojoc ha de recordar els teus punts; una tenda, els seus preus; el teu mòbil, la teua edat. Hui aprenem on guarda les dades un programa: les variables.

⏱ 3 hores 📦 Variables i tipus bàsics 🧮 Operadors + - * / % ⌨️ Primeres dades per teclat

1 · Introducció

On guarda els punts un videojoc?

Estàs jugant una partida i portes 1.250 punts, 3 vides i el nivell 4. Si el joc no recordara eixos números, no existiria la partida. En programació, eixa memòria amb etiqueta té nom: variable. I si l'usuari posa una altra cosa? El programa ho ha de tindre tot previst… anem a veure-ho.

2 · Què aprendrem?

Objectius del tema

  • Entendre què és una variable: una caixa amb nom on guardem una dada.
  • Triar el tipus adequat entre int, double, boolean, char i String.
  • Declarar, assignar i modificar valors sense por.
  • Calcular amb + - * / % i concatenar text.
  • Llegir dades del teclat amb Scanner.
3 · Teoria

Una idea, un exemple

3.1 · Una variable és una caixa

Imagina caixes d'emmagatzematge amb una etiqueta: dins hi cap una sola cosa alhora, i l'etiqueta diu el nom. En Java, a més, cada caixa té una forma: n'hi ha per a enters, per a decimals, per a text… Això és el tipus.

3.2 · Els cinc tipus que farem servir

TipusQuè guardaExemple del teu món
intEntersedat, punts, seguidors
doubleDecimalsnota mitjana, preu, temperatura
booleantrue / false«connectat?», «premium?»
charUn caràcterla inicial del teu nom, un grup 'B'
StringText (entre cometes dobles)nom, cançó, usuari d'una xarxa

3.3 · Declarar, assignar i modificar

Declarar és crear la caixa (int punts;); assignar és ficar-hi la dada (punts = 1250;). Es pot fer tot junt. I ací està la gràcia: el valor pot canviar mentre el programa roda.

Partida.java
public class Partida {
    public static void main(String[] args) {
        int punts = 0;            // declaració + assignació
        punts = 1250;             // modifiquem el valor
        punts = punts + 250;      // guanyem 250 punts més!

        double temperatura = 36.5;
        boolean connectat = true;
        char grup = 'B';          // un caràcter: cometes SIMPLES
        String nom = "Andrea";    // text: cometes DOBLES

        System.out.println(nom + " porta " + punts + " punts");
    }
}

3.4 · Operadors: la calculadora

Calculs.java
int diners = 20;
int preu = 7;

System.out.println(diners + preu);   // 27  (suma)
System.out.println(diners - preu);   // 13  (resta)
System.out.println(diners * preu);   // 140 (multiplicació)
System.out.println(diners / preu);   // 2   (!!) divisió ENTERA
System.out.println(diners % preu);   // 6   residu: el que "sobra"

double mitjana = (8.5 + 7 + 6.5) / 3;  // amb decimals, divisió normal
🚨 El parany del dia: 7 / 2 val 3

Si els dos números són int, Java fa divisió entera i es menja els decimals. Per a decimals de veres, cal que algun dels números siga double: 7.0 / 2 → 3.5. Este error costarà més d'un examen, ja ho veuràs.

3.5 · Concatenar: enganxar text

El símbol +, quan hi ha text pel mig, enganxa en lloc de sumar: "Hola, " + nom. Java converteix sol els números a text quan els enganxes a una cadena.

3.6 · Llegir del teclat: Scanner

Fins ara, les dades les posàvem nosaltres al codi. Ara li donem la volta: que les pose l'usuari. Scanner és una eina que llig del teclat.

Dades.java
import java.util.Scanner;   // "importa" esta eina (de moment, copia-la tal qual)

public class Dades {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);   // ja arribarem a què és això exactament

        System.out.print("Quants punts has fet? ");
        int punts = tec.nextInt();        // llig un enter del teclat

        System.out.print("I el teu nom? ");
        String nom = tec.next();          // llig una paraula

        System.out.println("Enhorabona, " + nom + ": " + punts + " punts!");
    }
}
🧘 De moment no cal entendre-ho tot

import i new Scanner(...) són paraules necessàries perquè la lectura funcione. De moment no necessitem entendre esta part; ja arribarem més avant. Hui, quedat amb això: nextInt() llig un enter, next() una paraula i nextLine() una línia sencera.

4 · Programació guiada

«Quants diners em queden?» pas a pas

Construïm un programa real: cobres la paga, compres un joc i vols saber què et queda. Cada pas, compila i executa abans de seguir.

1

Les caixes inicials

Crea el programa Carters.java amb dues variables: la teua paga (15 €) i el preu del joc (9.99 €). Quin tipus usem per als diners amb decimals?

double paga = 15;
double preuJoc = 9.99;
2

Calculem el que queda

Una tercera variable guarda el resultat de la resta. Imprimeix-la enganxada a un text.

double resta = paga - preuJoc;
System.out.println("Em queden " + resta + " euros");
3

Que ho diga l'usuari

Amb Scanner, demana la paga i el preu en lloc de deixar-los escrits. Prova amb valors diferents: el programa ja serveix per a qualsevol compra.

Scanner tec = new Scanner(System.in);
System.out.print("Quanta paga tens? ");
double paga = tec.nextDouble();
4

Un extra: el mòdul (%)

Si vols repartir la paga que et queda entre 3 amics a parts iguales (en euros sencers), quants euros sobren? Pista: %.

int euros = (int) resta;      // pas a enters: ja ho veurem, no passa res
System.out.println("Sobren " + euros % 3 + " euros");
5 · Errors habituals

On caurem (i com eixir-ne)

Divisió entera sorpresa

Què:
7 / 2 dona 3, no 3.5.
Per què:
dos int ⇒ divisió entera.
Detectar-ho:
resultats «estranyos» en fer divisions.
Corregir-ho:
usa double o escriu 7.0 / 2.

Cometes confoses

Què:
char c = "A"; peta.
Per què:
char vol cometes simples 'A'; String, dobles.
Detectar-ho:
«incompatible types» al compilar.
Corregir-ho:
canvia el tipus de cometa segons el tipus.

Majúscules i minúscules

Què:
Edat i edat són caixes diferents (o «cannot find symbol»).
Per què:
Java distingeix majúscules.
Detectar-ho:
l'error diu el símbol que no troba.
Corregir-ho:
escriu els noms sempre igual, en camelCase.

Usar abans de crear

Què:
imprimir punts sense haver-lo declarat.
Per què:
la caixa no existeix encara.
Detectar-ho:
«cannot find symbol: variable punts».
Corregir-ho:
declara la variable abans d'usar-la.
6 · Resum visual

Idees que es queden

📦Variable = caixa amb nom i tipus; el valor pot canviar.
🔢int enters · double decimals.
✅boolean = true/false · char = 'A' · String = "text".
🧮+ - * / % — i ull amb la divisió entera.
🔗+ amb text enganxa (concatena).
⌨️Scanner: nextInt(), nextDouble(), next().
🏷️Noms en camelCase: puntsJoc, notaFinal.
✏️; al final de cada instrucció. Sempre.
7 · Activitats

Tres sales d'entrenament

Mini exercicis (ràpids, a classe)

  1. Crea variables per a la teua edat, la teua altura i si t'agrada el futbol; imprimeix-les.
  2. Guarda 9 i 4 en dos int i imprimeix suma, resta, multiplicació, divisió i mòdul.
  3. Què imprimeix System.out.println("2 + 2 = " + 2 + 2);? Explica per què.
  4. Converteix 25 °C a Fahrenheit: F = C * 1.8 + 32, amb variables.
  5. Demana el teu nom amb Scanner i saluda'l.
  6. Un cinema: entrada 6.50 €, en pagues 10. Imprimeix el canvi usant variables.
Pregunta 01

Una variable és…

Solució: B. Eixa és la imatge mental del curs: caixa + nom + valor modificable.
Pregunta 02

Quin tipus uses per a guardar la nota mitjana 7.25?

Solució: A. Té decimals ⇒ double. Amb int es perdria la part decimal.
Pregunta 03

Quina línia està ben escrita?

Solució: C. String amb majúscula i el text entre cometes dobles, a la dreta del =.
Pregunta 04

int a = 7; int b = 2; System.out.println(a / b); imprimeix…

Solució: B. Dos enters ⇒ divisió entera: 3. El residu (1) el dona a % b.
Pregunta 05

System.out.println("1 + 1 = " + 1 + 1); imprimeix…

Solució: D. Com que comença amb text, cada + concatena: «1» i «1» s'enganxen. Per a sumar dins del text: "1 + 1 = " + (1 + 1).
Pregunta 06

Per a llegir un número enter del teclat usem…

Solució: A. nextInt() per a enters; next() llig una paraula de text.
Pregunta 07

int x = 5; x = x + 3; x = x * 2; — quant val x al final?

Solució: A. Pas a pas: 5+3=8 i 8*2=16. Les variables es modifiquen en ordre, línia a línia.
Pregunta 08

Quin valor és un boolean vàlid?

Solució: B. Sense cometes (no és text) i en anglés: true o false.
Pregunta 09

Volem guardar el residu de repartir 14 cromos entre 4 amics. Quin operador ho fa directament?

Solució: A. El mòdul dona el que sobra: 14 % 4 = 2. (Amb / sabríem quants toca cadascú: 3.)
Exercici 1

La compra de l'institut

Demana amb Scanner el preu d'un entrepà i el d'una beguda. Imprimeix el total i quant sobra si pagues amb 10 €.

Compra.java
import java.util.Scanner;

public class Compra {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        System.out.print("Preu de l'entrepà: ");
        double entrepa = tec.nextDouble();
        System.out.print("Preu de la beguda: ");
        double beguda = tec.nextDouble();

        double total = entrepa + beguda;
        System.out.println("Total: " + total + " euros");
        System.out.println("Sobren: " + (10 - total) + " euros");
    }
}
Exercici 2

Mitjana de dues notes

Demana dues notes (decimals) i mostra la mitjana. Compte amb la divisió: volem decimals de veres!

Mitjana2.java
import java.util.Scanner;

public class Mitjana2 {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        System.out.print("Primera nota: ");
        double n1 = tec.nextDouble();
        System.out.print("Segona nota: ");
        double n2 = tec.nextDouble();

        double mitjana = (n1 + n2) / 2;   // double: divisió normal
        System.out.println("La teua mitjana és " + mitjana);
    }
}
Exercici 3

Termòmetre °C → °F

Demana una temperatura en graus Celsius i mostra l'equivalent en Fahrenheit (F = C * 1.8 + 32).

Termometre.java
import java.util.Scanner;

public class Termometre {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        System.out.print("Temperatura en °C: ");
        double celsius = tec.nextDouble();

        double fahrenheit = celsius * 1.8 + 32;
        System.out.println(celsius + " °C són " + fahrenheit + " °F");
    }
}
Exercici 4

Fitxa de videojoc

Demana nom, edat i punts rècord. Imprimeix una «fitxa» amb eixes tres dades i el doble dels punts.

Fitxa.java
import java.util.Scanner;

public class Fitxa {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        System.out.print("Nom de jugador/a: ");
        String nom = tec.next();
        System.out.print("Edat: ");
        int edat = tec.nextInt();
        System.out.print("Punts rècord: ");
        int punts = tec.nextInt();

        System.out.println("=== FITXA ===");
        System.out.println(nom + ", " + edat + " anys");
        System.out.println("Rècord: " + punts + " (doble: " + punts * 2 + ")");
    }
}
