Classes i objectes

La programació orientada a objectes (POO) és com funciona el món real: un pla (la classe) i moltes còpies reals (els objectes). Hui construïm el primer Jugador del nostre videojoc.

⏱ 3 hores 📐 Classe = pla 🧍 Objecte = còpia real 🎮 Jugador i Cotxe

1 · Introducció

Un Jugador no és una variable

Un jugador de videojoc té nom, vides, punts, posició… Si ho guardàrem en variables soltes, amb dos jugadors ja tindríem nom1, nom2, vides1, vides2… un caos. Millor idea: crear un pla de Jugador una sola vegada i fabricar tants jugadors com vullguem.

2 · Què aprendrem?

Objectius del tema

  • Distingir classe i objecte (pla vs còpia real).
  • Definir una classe amb atributs i mètodes.
  • Crear objectes amb new i usar-los.
  • Llegir i canviar atributs amb el punt: jugador.vides.
  • Modelar objectes reals: un Jugador, un Cotxe, un Producte…
3 · Teoria

Una idea, un exemple

3.1 · La primera classe

Jugador.java
public class Jugador {

    // ATRIBUTS: les dades que guarda cada jugador
    String nom;
    int vides;
    int punts;

    // MÈTODES: el que sap fer
    public void perdreVida() {
        vides--;
        System.out.println(nom + " perd una vida. Li queden " + vides);
    }

    public boolean estaViu() {
        return vides > 0;
    }
}

Els atributs són el que té; els mètodes, el que sap fer. Dins d'un mètode de la classe pots usar els atributs directament, sense paràmetres: cada objecte treballa amb les seues dades.

3.2 · Fabricar objectes amb new

Partida.java
public class Partida {
    public static void main(String[] args) {
        Jugador j1 = new Jugador();     // fabrica un jugador nou
        j1.nom = "Maria";               // li posem les dades amb el punt
        j1.vides = 3;
        j1.punts = 120;

        Jugador j2 = new Jugador();
        j2.nom = "Joan";
        j2.vides = 2;
        j2.punts = 80;

        j1.perdreVida();               // Maria → 2 vides
        System.out.println(j1.vides);  // 2
        System.out.println(j2.vides);  // 2… de Joan! cadascú té les seues
    }
}

3.3 · Un objecte que es mou: el Cotxe

Ara li pegarem una volta: un objecte pot canviar el seu propi estat amb els seus mètodes.

Cotxe.java
public class Cotxe {
    String marca;
    int velocitat;      // km/h actuals

    public void accelera() {
        velocitat += 10;
    }

    public void fre() {
        if (velocitat >= 10) {
            velocitat -= 10;
        } else {
            velocitat = 0;
        }
    }
}

// al main:
Cotxe c = new Cotxe();
c.marca = "Seat";
c.accelera();
c.accelera();
System.out.println(c.marca + " va a " + c.velocitat + " km/h");   // 20

3.4 · Arrays d'objectes

Equip.java
Jugador[] equip = new Jugador[3];      // 3 llocs per a jugadors

for (int i = 0; i < equip.length; i++) {
    equip[i] = new Jugador();          // omplim cada lloc
    equip[i].vides = 3;
    System.out.println(equip[i].estaViu());   // true
}

Combinant tema 4 + tema 6: un array de jugadors és la llista d'usuaris d'una app, els productes d'una botiga, els cotxes d'un pàrquing…

4 · Programació guiada

El nostre primer videojoc 🎮

Dos jugadors s'enfronten: cadascú té vides, i un atac li lleva una vida a l'altre. Guanya qui es queda dempeus.

1

La classe Jugador

Atributs: nom, vides, punts. Mètode ataca() que suma punts a qui ataca.

public class Jugador {
    String nom;
    int vides;
    int punts;

    public void ataca() {
        punts += 10;
        System.out.println(nom + " ataca! (+10 punts, total " + punts + ")");
    }
}
2

Qui rep el colp

Mètode repColp(): lleva una vida i avisa si ha caigut.

public void repColp() {
    vides--;
    if (estaViu()) {
        System.out.println(nom + " aguanta! (" + vides + " vides)");
    } else {
        System.out.println(nom + " ha caigut! 💀");
    }
}
3

Crea els dos jugadors

Al main d'una classe Combat, fabrica'ls i posa'ls nom i 3 vides.

Jugador a = new Jugador();
a.nom = "Maria";
a.vides = 3;

Jugador b = new Jugador();
b.nom = "Joan";
b.vides = 3;
4

El combat, torn a torn

Un bucle while mentre els dos estiguen vius: cada torn, A ataca i B rep el colp (i després a l'inrevés, per ser justos).

while (a.estaViu() && b.estaViu()) {
    a.ataca();
    b.repColp();
    if (b.estaViu()) {
        b.ataca();
        a.repColp();
    }
}
5

Qui ha guanyat?

Quan el bucle acaba, un dels dos ha caigut. Mostra el guanyador amb un if i els punts finals de cadascú. I si vols sorpreses: fes que els atacs fallen la meitat de les vegades amb Random.

if (a.estaViu()) {
    System.out.println("Guanya " + a.nom + " amb " + a.punts + " punts!");
} else {
    System.out.println("Guanya " + b.nom + " amb " + b.punts + " punts!");
}
5 · Errors habituals

Errors de principiant de POO

Oblidar el new

Què:
error NullPointerException quan uses l'objecte.
Per què:
has declarat la variable però mai has fabricat l'objecte.
Detectar-ho:
peta just en el primer ..
Corregir-ho:
j = new Jugador(); abans d'usar-lo.

Confondre classe i objecte

Què:
«la classe Jugador té 3 vides»… no, cada OBJECTE en té.
Per què:
la classe és el pla, no guarda dades reals.
Detectar-ho:
canvies les dades d'un objecte i penses que canvien totes.
Corregir-ho:
pensa sempre: «quina còpia estic tocant?».

Posar tot el codi dins de la classe

Què:
escrivim el programa dins de Jugador i no compila.
Per què:
el programa arranca des del main, que viu en una classe «cap».
Detectar-ho:
«class, interface or enum expected».
Corregir-ho:
Jugador.java = pla; Combat.java = programa amb main.

Mètodes sense objecte

Què:
perdreVida() a seques no compila.
Per què:
cal dir QUI perd la vida.
Detectar-ho:
«non-static method cannot be referenced».
Corregir-ho:
j1.perdreVida(); — primer l'objecte, després el punt.
6 · Resum visual

Idees que es queden

📐Classe = pla amb atributs (dades) i mètodes (accions).
🧍Objecte = còpia real fabricada amb new.
🔗Punt per a accedir: jugador.vides, j1.ataca().
👯Cada objecte té les SEUES dades, independents.
🎮Modelar = convertir coses reals en classes (Jugador, Cotxe, Producte).
📦Arrays d'objectes: molts Jugadors en una llista.
7 · Activitats

Tres sales d'entrenament

Mini exercicis (ràpids, a classe)

  1. Crea la classe Producte amb atributs nom i preu. Al main, fabrica'n dos i mostra els seus noms.
  2. Afig a Producte un mètode void mostraFitxa() que imprimeixi «Nom — Preu €».
  3. Crea la classe Mascota amb nom, energia i un mètode juga() que resti 10 d'energia (sense baixar de 0).
  4. Quantes vides té j2 després de j1.perdreVida() si tots dos començaven amb 3?
  5. Què passa si fas Jugador j; j.nom = "Pau"; sense new?
  6. Modela la classe Llibre: quins atributs li posaries? Quins mètodes?
Pregunta 01

Una classe és…

Solució: B. La classe és el pla 📐; els objectes són les còpies reals fabricades amb new.
Pregunta 02

Què fa new Jugador()?

Solució: C. new construeix un objecte nou seguint el pla de la classe.
Pregunta 03

Com accedim a les vides del jugador j1?

Solució: A. En Java s'usa el punt: objecte + . + atribut o mètode.
Pregunta 04

Què passa si declares Jugador j; i fas j.nom = "Pau"; sense new?

Solució: D. Sense new la variable no apunta a cap objecte: no hi ha res on guardar el nom.
Pregunta 05

Si j1 i j2 són dos objectes Jugador i fem j1.vides = 1;, les vides de j2…

Solució: B. Dos objectes = dues caixes de dades independents, encara que siguen del mateix pla.
Pregunta 06

Dins d'un mètode de la classe Jugador, per a restar una vida escrivim…

Solució: C. Dins de la classe, l'atribut s'usa directament: cada objecte ja sap quines són les seues dades.
Pregunta 07

Què imprimeix?

Cotxe c = new Cotxe();
c.velocitat = 30;
c.fre();
System.out.println(c.velocitat);
// fre() fa: velocitat -= 10 si pot, si no 0
Solució: A. 30 - 10 = 20. El mètode ha canviat l'estat del seu propi objecte.
Pregunta 08

Un array de Jugador[3] recent creat…

Solució: D. L'array crea els LLOCS; els objectes els fabriques tu: equip[i] = new Jugador();.
Pregunta 09

Per què ens serveix la POO?

Solució: B. Pensa en Jugadors i Cotxes, no en variables soltes: el codi s'assembla al problema.
Pregunta 10

Després d'executar 3 vegades new Jugador() (guardant cada un en una variable distinta), quants objectes Jugador hi ha?

Solució: C. Cada new fabrica un objecte nou i independent. Tres new = tres jugadors amb les seues dades.
Exercici 1

La botiga de Productes 🛒

Classe Producte amb nom, preu i mètode aplicaDescompte(int percent) que rebaixe el preu. Crea 3 productes, aplica un 10% a un d'ells i mostra les fitxes.

Producte.java + Botiga.java
public class Producte {
    String nom;
    double preu;

    public void aplicaDescompte(int percent) {
        preu = preu - (preu * percent / 100.0);
    }

    public void mostraFitxa() {
        System.out.println(nom + " — " + preu + " €");
    }
}

public class Botiga {
    public static void main(String[] args) {
        Producte p1 = new Producte();
        p1.nom = "Auriculars";
        p1.preu = 30;

        Producte p2 = new Producte();
        p2.nom = "Teclat";
        p2.preu = 20;

        Producte p3 = new Producte();
        p3.nom = "Ratolí";
        p3.preu = 12;

        p1.aplicaDescompte(10);
        p1.mostraFitxa();   // 27.0 €
        p2.mostraFitxa();
        p3.mostraFitxa();
    }
}
Exercici 2

El compte bancari 🏦

Classe Compte amb titular i saldo, i mètodes ingressar(double) i retirar(double) (que no permeta quedar en negatiu: avisa i no faces res).

Compte.java
public class Compte {
    String titular;
    double saldo;

    public void ingressar(double quantitat) {
        saldo += quantitat;
        System.out.println("Ingrés de " + quantitat + " €. Saldo: " + saldo);
    }

    public void retirar(double quantitat) {
        if (quantitat > saldo) {
            System.out.println("Saldo insuficient!");
        } else {
            saldo -= quantitat;
            System.out.println("Reintegrament de " + quantitat + " €. Saldo: " + saldo);
        }
    }
}
// prova: ingressar 100, retirar 30 (bé), retirar 90 (saldo insuficient)
Exercici 3

La carretera 🚗

Classe Cotxe amb marca, velocitat i km. Mètodes: accelera() (+10 km/h, màxim 120), fre() i avansa() (suma la velocitat als km). Fes una volta de 5 accions al teu cotxe i mostra l'informe final.

Cotxe.java
public class Cotxe {
    String marca;
    int velocitat;
    int km;

    public void accelera() {
        if (velocitat < 120) {
            velocitat += 10;
        }
    }

    public void fre() {
        if (velocitat >= 10) {
            velocitat -= 10;
        } else {
            velocitat = 0;
        }
    }

    public void avanca() {
        km += velocitat;
    }
}

public class Carretera {
    public static void main(String[] args) {
        Cotxe c = new Cotxe();
        c.marca = "Seat";
        for (int volta = 1; volta <= 5; volta++) {
            c.accelera();
            c.avanca();
            System.out.println("Volta " + volta + ": " + c.velocitat + " km/h, " + c.km + " km");
        }
    }
}
Exercici 4

El comptador 🔢

Crea una classe Comptador amb un atribut valor i tres mètodes: incrementar(), decrementar() (que mai baixe de 0) i mostra(). Al main, fes una xicoteta simulació: puja dos voltes, baixa una, mostra, i intenta baixar per davall de zero.

Comptador.java
public class Comptador {
    int valor;

    public void incrementar() {
        valor++;
    }

    public void decrementar() {
        if (valor > 0) {
            valor--;
        }
    }

    public void mostra() {
        System.out.println("El comptador val " + valor);
    }
}

public class ProvaComptador {
    public static void main(String[] args) {
        Comptador c = new Comptador();
        c.incrementar();
        c.incrementar();
        c.decrementar();
        c.mostra();       // 1
        c.decrementar();
        c.decrementar();  // la segona no fa res: ja està en 0
        c.mostra();       // 0
    }
}
