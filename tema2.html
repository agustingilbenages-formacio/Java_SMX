Prendre decisions

El mòbil et deixa entrar si la contrasenya és correcta; el videojoc et puja de nivell si tens prou punts. Hui els nostres programes aprenen a dir «si passa això, fes allò».

⏱ 3 hores ⚖️ Comparacions i lògica 🔀 if / else / else if 🎚️ Primer contacte amb switch

1 · Introducció

Quina condició ha de complir-se?

Obri el mòbil amb la cara: si la càmera reconeix la teua cara, es desbloqueja; si no, et demana el PIN. Eixa pregunta —«quina condició ha de complir-se perquè passe açò?»— és la pregunta estrella del tema. La farem servir tant que la somniaràs. 😄

2 · Què aprendrem?

Objectius del tema

  • Comparar dades amb == != < > <= >=.
  • Combinar condicions amb && (i), || (o) i ! (no).
  • Dirigir el programa amb if, else i else if.
  • Triar entre moltes opcions amb un switch senzill.
3 · Teoria

Una idea, un exemple

3.1 · Preguntes amb resposta true/false

Tota decisió naix d'una condició: una pregunta que Java respon amb true o false. Els operadors per a preguntar:

Preguntes.java
int edat = 16;

System.out.println(edat == 16);   // true  (igual que)
System.out.println(edat != 16);   // false (distint de)
System.out.println(edat >= 18);   // false (major o igual)
System.out.println(edat < 18);    // true  (menor que)
🚨 El clàssic dels clàssics: = no és ==

= assigna (fica un valor a la caixa); == pregunta si són iguals. Confondre'ls és l'error número u del Tema 2.

3.2 · if / else: el carril de les decisions

Acces.java
String contrasenya = "somnis2026";
String escrita = "somnis2026";   // imagina que la llig del teclat

if (escrita.equals(contrasenya)) {
    System.out.println("Desbloquejat ✔");
} else {
    System.out.println("Contrasenya incorrecta ✖");
}

3.3 · else if: més de dos camins

Nivells.java
int punts = 850;

if (punts >= 1000) {
    System.out.println("Nivell OR 🥇");
} else if (punts >= 500) {
    System.out.println("Nivell PLATA 🥈");   // 850 cau ací
} else {
    System.out.println("Nivell BRONZE 🥉");
}

Java comprova de dalt a baix i només entra en el primer camí que complisca. Per això l'ordre de les condicions importa molt.

3.4 · I, O, NO: combinar preguntes

Entrada.java
int edat = 16;
boolean ambAdult = false;

// Entrada al parc: majors de 12, O menors acompanyats
if (edat > 12 || (edat <= 12 && ambAdult)) {
    System.out.println("Pots passar!");
} else {
    System.out.println("Encara no, menudet.");
}

// El ! nega: "no està connectat"
boolean connectat = false;
if (!connectat) {
    System.out.println("Connecta't al wifi primer!");
}
  • && = «i»: les dues han de ser certes.
  • || = «o»: amb que una siga certa, n'hi ha prou.
  • ! = «no»: li dona la volta a la resposta.

3.5 · switch: el menú del dia

Quan compares un valor contra opcions concretes, el switch queda més net. Amb fletxes -> no cal ni break.

Menu.java
int opcio = 2;

switch (opcio) {
    case 1 -> System.out.println("Jugar partida");
    case 2 -> System.out.println("Vore rècords");
    case 3 -> System.out.println("Eixir del joc");
    default -> System.out.println("Opció no vàlida");
}
4 · Programació guiada

El porter de la discoteca 🎟️

Fem un programa que decidix qui entra a una sala: majoria d'edat i entrada comprada. Pas a pas, com sempre.

1

Demana les dades

Llig l'edat i si té entrada (1 sí, 0 no, guardat en un int de moment).

Scanner tec = new Scanner(System.in);
System.out.print("Quants anys tens? ");
int edat = tec.nextInt();
System.out.print("Tens entrada? (1/0) ");
int entrada = tec.nextInt();
2

La primera decisió

Si és major d'edat, missatge de «cap avant»; si no, «ho sentim, encara no».

if (edat >= 18) {
    System.out.println("Cap avant!");
} else {
    System.out.println("Ho sentim, encara no.");
}
3

Ara li peguem una volta: dues condicions

Només entra si és major i té entrada. Combina amb &&. Prova els quatre casos: 20 amb entrada, 20 sense, 15 amb i 15 sense.

if (edat >= 18 && entrada == 1) {
    System.out.println("Benvingut/da a la sala!");
} else {
    System.out.println("No pots entrar.");
}
4

El detall pro: preu segons edat

Abans de decidir si entra, mostra el preu de l'entrada: 5 € si és menor de 18 (acompanyat), 12 € si no, amb else if.

if (edat < 18) {
    System.out.println("Entrada juvenil: 5 €");
} else {
    System.out.println("Entrada adulta: 12 €");
}
5 · Errors habituals

Trampes del Tema 2

= en lloc de ==

Què:
if (edat = 18) no compara: assigna.
Per què:
un sol = és assignació.
Detectar-ho:
«incompatible types» o comportament raríssim.
Corregir-ho:
dos signes iguals per a preguntar.

Condicions impossibles

Què:
if (nota >= 5 && nota < 5) mai és certa.
Per què:
cap número complix les dues alhora.
Detectar-ho:
el camí mai s'executa, encara que compile.
Corregir-ho:
pensa en la recta numèrica; potser volies ||.

Oblidar les claus

Què:
sense { }, l'if només «agarra» la primera línia.
Per què:
Java agrupa així per defecte.
Detectar-ho:
línies que s'executen «sempre».
Corregir-ho:
claus sempre, encara que siga una línia.

Comparar text amb ==

Què:
if (nom == "Pau") falla «sense motiu».
Per què:
amb cadenes, == compara una altra cosa (ja ho veurem).
Detectar-ho:
condicions que pareixen certes i donen false.
Corregir-ho:
nom.equals("Pau").
6 · Resum visual

Idees que es queden

❓Tota condició acaba en true o false.
⚖️== != < > <= >= per a comparar.
🔗&& les dues · || una basta · ! nega.
🔀if / else if / else: de dalt a baix, primer que complisca.
🎚️switch per a opcions concretes (menús!).
📝Text es compara amb .equals().
🧠Pregunta màgica: «quina condició ha de complir-se?»
7 · Activitats

Tres sales d'entrenament

Mini exercicis (ràpids, a classe)

  1. Escriu les condicions: «edat entre 13 i 19», «nota distinta de 5», «no connectat».
  2. int a = 4, b = 9; — què dona a > b? I a < b || a == 4? Comprova-ho amb println.
  3. if/else: imprimeix «majoria d'edat» o «menoria» segons l'edat llegida.
  4. Cadena d'else if: nota ≥9 Excel·lent, ≥7 Notable, ≥5 Aprovat, altrament Suspés.
  5. switch amb el número de dia de la setmana (1-7) que imprima si és cap de setmana.
  6. Què passa si poses if (edat = 18)? Llig l'error i explica'l.
Pregunta 01

Per a preguntar «edat igual a 16» escrivim…

Solució: C. Doble igual per a comparar; un de sol assigna.
Pregunta 02

int nota = 4; Què imprimeix if (nota >= 5) { println("Aprovat"); } else { println("Suspés"); }?

Solució: A. 4 >= 5 és false, així que es fa el camí de l'else.
Pregunta 03

L'operador que exigix que les dues condicions siguen certes és…

Solució: B. && és el «i»: tot ha de ser true.
Pregunta 04

boolean plou = false; — quan és certa la condició !plou?

Solució: D. El ! nega: si no plou (false), !plou és true.
Pregunta 05

En una cadena if / else if / else, quants camins s'executen com a màxim?

Solució: B. De dalt a baix, entra en el primer true i salta la resta.
Pregunta 06

Per a comparar el text de la variable nom amb "Pau" usem…

Solució: C. Les cadenes es comparen amb .equals(); el == enganya.
Pregunta 07

Quina condició expressa «edat entre 13 i 19, tots dos inclosos»?

Solució: A. En Java cal escriure les dues comparacions unides per &&; la B és com ho faríem en paper, però no compila com pensem; la C seria «qualsevol edat».
Pregunta 08

int a = 5; — què val a > 3 || a > 10 ?

Solució: D. Amb || n'hi ha prou amb una de certa: 5 > 3 ja val true.
Pregunta 09

Per a un menú amb les opcions 1, 2 i 3, l'estructura més neta és…

Solució: B. Valors concrets contra opcions concretes: territori natural del switch.
Exercici 1

Aprovat o suspés, amb missatge personalitzat

Llig una nota decimal. Si és 5 o més, «Aprovat 🎉»; si no, «A recuperar-se 💪». I si és exactament un 10, afig «Matrícula d'honor!».

Nota.java
import java.util.Scanner;

public class Nota {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        System.out.print("Quina nota has tret? ");
        double nota = tec.nextDouble();

        if (nota >= 5) {
            System.out.println("Aprovat!");
            if (nota == 10) {
                System.out.println("Matrícula d'honor!");
            }
        } else {
            System.out.println("A recuperar-se!");
        }
    }
}
Exercici 2

El preu del cinema

Entrada de cine: 6 € si tens menys de 13 anys, 8 € si en tens entre 13 i 64, i 5 € a partir de 65. Llig l'edat i mostra el preu amb if / else if / else.

Cine.java
import java.util.Scanner;

public class Cine {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        System.out.print("Quants anys tens? ");
        int edat = tec.nextInt();

        if (edat < 13) {
            System.out.println("Entrada infantil: 6 €");
        } else if (edat <= 64) {
            System.out.println("Entrada general: 8 €");
        } else {
            System.out.println("Entrada major: 5 €");
        }
    }
}
Exercici 3

Contrasenya amb dues comprovacions

Demana usuari i contrasenya. Només entra si l'usuari és "admin" i la contrasenya és "1234". Si falla només una de les dues, diga quina ha fallat.

Login.java
import java.util.Scanner;

public class Login {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        System.out.print("Usuari: ");
        String usuari = tec.next();
        System.out.print("Contrasenya: ");
        String clau = tec.next();

        if (usuari.equals("admin") && clau.equals("1234")) {
            System.out.println("Dins! Hola, admin.");
        } else if (!usuari.equals("admin")) {
            System.out.println("L'usuari no existeix.");
        } else {
            System.out.println("Contrasenya incorrecta.");
        }
    }
}
