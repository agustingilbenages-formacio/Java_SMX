Treballar amb moltes dades: els arrays

Vint-i-cinc alumnes, vint-i-cinc notes. Vint-i-cinc variables? Ni parlar-ne. Un array és un calaix amb molts compartiments numerats: una sola variable per a guardar-ho tot.

⏱ 3 hores 📦 Arrays i índexs 🔁 Recórrer amb for 🔍 Cercar, comptar, màxim i mínim ✍️ Introducció a String

1 · Introducció

Les dades de tota la classe, en un lloc

Mira què passa ací: un videojoc guarda les puntuacions de totes les partides, el mòbil guarda tots els teus contactes, i l'institut guarda les notes de tots els alumnes. Coses del mateix tipre, moltes i juntes. Els arrays són la primera eina que usa tot programador per a organitzar-les.

2 · Què aprendrem?

Objectius del tema

  • Crear arrays i entendre els índexs (compten des de 0!).
  • Recórrer un array amb un bucle for.
  • Operacions bàsiques: sumar, comptar, cercar, màxim i mínim.
  • Evitar l'error número u: eixir-se dels marges de l'array.
  • Conèixer String com a «array de lletres» i els seus mètodes bàsics.
3 · Teoria

Una idea, un exemple

3.1 · Crear un array

Notes.java
int[] notes = new int[5];      // un calaix de 5 compartiments

notes[0] = 7;                  // el primer compartiment és el 0!
notes[1] = 9;
notes[2] = 5;
notes[3] = 8;
notes[4] = 6;

System.out.println(notes[0]);          // 7
System.out.println(notes.length);      // 5 — quantitat de compartiments

3.2 · Recórrer l'array amb for

Ací és on comença a tindre gràcia: els índexs són números, així que un bucle pot passejar-se per tots els compartiments.

Recorregut.java
int total = 0;
for (int i = 0; i < notes.length; i++) {
    total += notes[i];                     // acumula cada nota
}
System.out.println("Mitjana: " + ((double) total / notes.length));

Fixa't: i < notes.length (sense =), perquè l'últim índex vàlid és length - 1.

3.3 · Cercar, comptar, màxim i mínim

Les tres operacions estrella. Totes segueixen el mateix patró: recorrer i comparar.

Operacions.java
// COMPTAR aprovats
int aprovats = 0;
for (int i = 0; i < notes.length; i++) {
    if (notes[i] >= 5) {
        aprovats++;
    }
}

// MÀXIM: comença pensant que el primer és el millor
int maxima = notes[0];
for (int i = 1; i < notes.length; i++) {
    if (notes[i] > maxima) {
        maxima = notes[i];
    }
}

3.4 · String: text que es pot examinar

Un String és text, i es comporta com una fila de lletres amb el seu índex. Els seus mètodes bàsics:

Text.java
String nom = "Maria";

nom.length()          // 5 lletres
nom.charAt(0)         // 'M' — la primera
nom.toUpperCase()     // "MARIA"
nom.equals("Maria")   // true — comparar text SEMPRE amb .equals()

String[] classe = {"Maria", "Joan", "Aina"};
System.out.println(classe[0] + " és la primera");
4 · Programació guiada

El butlletí de notes 📋

Un programa de profe: guarda 5 notes, calcula la mitjana i diu la nota més alta i la més baixa. A poc a poc.

1

Crea l'array i ompli'l

Cinq compartiments i les notes escrites a mà (després les demanarem per teclat).

int[] notes = {7, 9, 5, 8, 6};   // forma ràpida d'omplir-lo
2

Mostra-les totes

Un for que imprimeix cada nota amb el seu índex.

for (int i = 0; i < notes.length; i++) {
    System.out.println("Nota " + i + ": " + notes[i]);
}
3

Calcula la mitjana

Acumulador + suma, com al tema 3. Compte amb la divisió: converteix a double per a no perdre decimals!

int total = 0;
for (int i = 0; i < notes.length; i++) {
    total += notes[i];
}
double mitjana = (double) total / notes.length;
4

La millor i la pitjor

Dos recorreguts (o un de sol amb dos ifs): màxim i mínim, començant sempre pel primer element.

int maxima = notes[0], minima = notes[0];
for (int i = 1; i < notes.length; i++) {
    if (notes[i] > maxima) maxima = notes[i];
    if (notes[i] < minima) minima = notes[i];
}
5

Resultat complet

Imprimeix mitjana, màxima i mínima. I si l'usuari posa una altra cosa… per exemple, vol saber quants han aprovat? Afig un comptador amb if (notes[i] >= 5).

System.out.println("Mitjana: " + mitjana);
System.out.println("Millor nota: " + maxima);
System.out.println("Pitjor nota: " + minima);
System.out.println("Aprovats: " + aprovats + " de " + notes.length);
5 · Errors habituals

Els clàssics dels arrays

Eixir-se de l'array 💥

Què:
error ArrayIndexOutOfBoundsException (o un valor rar).
Per què:
has demanat un índex que no existeix (començar en 1, o i <= length).
Detectar-ho:
el missatge d'error diu l'índex culpable.
Corregir-ho:
els índexs van de 0 a length - 1.

Mitjana sense decimals

Què:
la mitjana de 7 i 8 dona 7.
Per què:
divisió d'enters: Java talla els decimals (tema 1!).
Detectar-ho:
resultats «redons» sospitosos.
Corregir-ho:
(double) total / notes.length.

Comparar text amb ==

Què:
dos textos iguals no «són iguals».
Per què:
== compara on viuen, no què diuen.
Detectar-ho:
la comparació falla «per casualitat».
Corregir-ho:
nom.equals("Maria"), sempre.

Màxim que comença en 0

Què:
el màxim d'unes notes negatives (o un mínim fals) no s'encerta.
Per què:
has suposat que tot seria positiu.
Detectar-ho:
resultat 0 quan cap valor no ho era.
Corregir-ho:
inicia màxim/mínim amb array[0], no amb 0.
6 · Resum visual

Idees que es queden

📦Array = moltes dades del mateix tipus en una sola variable.
0️⃣Els índexs comencen en 0; l'últim és length - 1.
🔁Recorregut clàssic: for (i = 0; i < a.length; i++).
🧮Suma, mitjana, comptar, cercar, màxim i mínim: tot és recorrer + comparar.
✍️String: .length(), .charAt(), .toUpperCase(), .equals().
🚫Compara text amb .equals(), mai amb ==.
7 · Activitats

Tres sales d'entrenament

Mini exercicis (ràpids, a classe)

  1. Crea un array amb les edats de 4 amics i mostra-les totes amb un for.
  2. Quants elements té int[] a = new int[10];? Quin és l'últim índex vàlid?
  3. Recorre l'array d'edats i mostra només les majors de 16.
  4. Compta quants valors d'un array són parells.
  5. Crea String[] dies amb els dies de la setmana i imprimeix el del mig.
  6. Què val "Programació".charAt(3)? Comprova-ho comptant des de 0.
Pregunta 01

Quin és l'índex del PRIMER element d'un array?

Solució: B. Sempre 0. El primer és array[0].
Pregunta 02

En int[] notes = new int[5];, quin és l'últim índex vàlid?

Solució: C. Índexs 0, 1, 2, 3 i 4 → l'últim és length - 1 = 4.
Pregunta 03

Amb int[] notes = {7, 9, 5, 8, 6};, què val notes[2]?

Solució: A. Índex 0→7, 1→9, 2→5. El tercer element val 5.
Pregunta 04

Què passa si executes notes[5] en un array de 5 elements?

Solució: D. L'índex 5 no existeix: Java para el programa i t'avisa amb eixe nom tan llarg.
Pregunta 05

Per a recórrer un array sencer amb for, la condició correcta és…

Solució: B. Amb <= t'eixiries de l'array en l'última volta. La C es deixaria l'últim element.
Pregunta 06

Què fa nom.charAt(0) si nom = "Maria"?

Solució: C. charAt retorna la lletra de l'índex indicat; la primera (índex 0) és la 'M'.
Pregunta 07

Què imprimeix este codi?

int[] a = {2, 4, 6};
int suma = 0;
for (int i = 0; i < a.length; i++) {
    suma += a[i];
}
System.out.println(suma);
Solució: A. 2 + 4 + 6 = 12, acumulat volta a volta.
Pregunta 08

Per a comprovar si dos String tenen el mateix text s'usa…

Solució: D. nom.equals("text"). El == compara referències, no contingut.
Pregunta 09

Per a calcular el MÀXIM d'un array, com l'inicialitzes?

Solució: B. Començant pel primer element funciona sempre, encara que tots els valors siguen negatius.
Exercici 1

L'inventari de la botiga 🛒

Array amb 5 preus. Mostra cada preu, el total, el més car i el més barat.

Inventari.java
public class Inventari {
    public static void main(String[] args) {
        double[] preus = {2.50, 7.90, 1.20, 12.00, 4.75};

        double total = 0, car = preus[0], barat = preus[0];
        for (int i = 0; i < preus.length; i++) {
            System.out.println("Producte " + i + ": " + preus[i] + " €");
            total += preus[i];
            if (preus[i] > car) car = preus[i];
            if (preus[i] < barat) barat = preus[i];
        }
        System.out.println("Total: " + total + " €");
        System.out.println("El més car: " + car + " € · El més barat: " + barat + " €");
    }
}
Exercici 2

Cerca el teu nom

Array amb 6 noms. Demana un nom i digues si hi és i en quina posició (o que no l'has trobat).

CercaNom.java
import java.util.Scanner;

public class CercaNom {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        String[] noms = {"Maria", "Joan", "Aina", "Pau", "Laia", "Marc"};

        System.out.print("Quin nom busques? ");
        String buscat = tec.nextLine();

        boolean trobat = false;
        for (int i = 0; i < noms.length; i++) {
            if (noms[i].equals(buscat)) {
                System.out.println("El tenim a la posició " + i);
                trobat = true;
            }
        }
        if (!trobat) {
            System.out.println(buscat + " no està a la llista");
        }
    }
}
Exercici 3

Notes demanades per teclat

Demana 5 notes (0-10, valida-les amb while), guarda-les en un array i mostra mitjana, aprovats i suspensos.

Butlleti.java
import java.util.Scanner;

public class Butlleti {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        int[] notes = new int[5];

        for (int i = 0; i < notes.length; i++) {
            System.out.print("Nota " + (i + 1) + " (0-10): ");
            notes[i] = tec.nextInt();
            while (notes[i] < 0 || notes[i] > 10) {
                System.out.print("No val! Torna-ho a provar: ");
                notes[i] = tec.nextInt();
            }
        }

        int total = 0, aprovats = 0;
        for (int i = 0; i < notes.length; i++) {
            total += notes[i];
            if (notes[i] >= 5) aprovats++;
        }
        System.out.println("Mitjana: " + ((double) total / notes.length));
        System.out.println("Aprovats: " + aprovats + " · Suspesos: " + (notes.length - aprovats));
    }
}
