Mètodes: donar nom als trossets

Si una recepta funciona, la guardes i li poses nom: «paella de la iaia». En programació fem el mateix: agafem un tros de codi que funciona, li posem nom i el reutilitzem quan volem. Això són els mètodes.

⏱ 3 hores 📦 Paràmetres (entrades) ↩️ return (eixida) 🖨️ void (només fa, no torna)

Material creat per Agustín Gil - IES La vereda 2026 · Llicència CC BY-NC 4.0

1 · Introducció

El codi que es repeteix, cansa

Ara li pegarem una volta: ja has copiat i enganxat el mateix tros de codi tres vegades i, quan calia canviar algo, ho havies de canviar als tres llocs (i segur que te n'has deixat un). Els mètodes arreglen això: escriu-ho una volta, usa-ho mil.

2 · Què aprendrem?

Objectius del tema

  • Entendre per què dividim el codi en trossets amb nom.
  • Crear mètodes amb paràmetres: dones dades, et fan la faena.
  • Tornar resultats amb return.
  • Crear mètodes void quan només cal fer algo, no tornar res.
  • Cridar mètodes des del main i d'altres mètodes.
3 · Teoria

Una idea, un exemple

3.1 · Un mètode que torna algo

Quadrats.java
public class Quadrats {

    // el mètode: rep un int i en torna un int
    public static int quadrat(int num) {
        return num * num;
    }

    public static void main(String[] args) {
        System.out.println(quadrat(4));    // 16
        System.out.println(quadrat(10));   // 100
        int area = quadrat(3);             // el guardem en una variable
    }
}

Anatomia: public static (de moment copia-ho tal qual; ja arribarem a entendre-ho), el tipus que torna (int), el nom i els paràmetres entre parèntesis.

3.2 · Més d'un paràmetre

Mitjanes.java
public static double mitjana(double a, double b) {
    return (a + b) / 2;
}

// al main:
System.out.println(mitjana(7, 8));   // 7.5
System.out.println(mitjana(0, 10));  // 5.0

L'ordre importa: el primer valor que passes va al primer paràmetre, i així successivament.

3.3 · void: mètodes que només fan

Si el mètode només ha de fer algo (imprimir, dibuixar, saludar) i no cal que torne cap resultat, el tipus és void («buit») i no hi ha return de valor.

Salutacio.java
public static void saluda(String nom) {
    System.out.println("Hola, " + nom + "! Benvingut/da 👋");
}

// al main:
saluda("Maria");
saluda("Joan");

3.4 · Mètodes dins de bucles i ifs

Un mètode es pot cridar des de qualsevol lloc, tantes voltes com vullgues. Fins i tot des d'un altre mètode o dins d'un bucle:

TaulaDeQuadrats.java
for (int i = 1; i <= 5; i++) {
    System.out.println("El quadrat de " + i + " és " + quadrat(i));
}
4 · Programació guiada

La calculadora 🧮

Una calculadora amb menú. Cada operació serà un mètode, i el main serà el cap que organitza la faena.

1

El primer mètode: sumar

Dos paràmetres, un return. Prova'l des del main abans de seguir.

public static double suma(double a, double b) {
    return a + b;
}
2

La resta de mètodes

resta, producte i divisio, seguint el mateix patró. Què faràs si divideixen entre 0?

public static double divisio(double a, double b) {
    if (b == 0) {
        System.out.println("No es pot dividir entre 0!");
        return 0;
    }
    return a / b;
}
3

Un mètode void per al menú

Imprimir el menú és una faena repetida: fem-ne un mètode void mostraMenu().

public static void mostraMenu() {
    System.out.println("1 · Sumar");
    System.out.println("2 · Restar");
    System.out.println("3 · Multiplicar");
    System.out.println("4 · Dividir");
    System.out.print("Tria una opció: ");
}
4

El main organitza

Demana l'opció amb un switch (tema 2) i crida el mètode que toca. Mira que curt que queda el main!

mostraMenu();
int opcio = tec.nextInt();
System.out.print("Primer número: ");
double a = tec.nextDouble();
System.out.print("Segon número: ");
double b = tec.nextDouble();

switch (opcio) {
    case 1: System.out.println("Resultat: " + suma(a, b)); break;
    case 2: System.out.println("Resultat: " + resta(a, b)); break;
    case 3: System.out.println("Resultat: " + producte(a, b)); break;
    case 4: System.out.println("Resultat: " + divisio(a, b)); break;
    default: System.out.println("Opció no vàlida");
}

5 · Errors habituals

Errors amb nom i cognoms

«Missing return statement»

Què:
no compila: falta un return.
Per què:
has promés tornar un int i hi ha camins sense return.
Detectar-ho:
el compilador t'ho diu exactament.
Corregir-ho:
assegura que TOTS els camins del mètode acaben en return.

Paràmetres desordenats

Què:
resta(3, 10) dona -7 quan volies 7.
Per què:
l'ordre dels valors ha de coincidir amb l'ordre dels paràmetres.
Detectar-ho:
resultats «al revés».
Corregir-ho:
comprova la definició: quin paràmetre va primer?

Variables que «no existeixen»

Què:
des del main no veus una variable creada dins d'un mètode.
Per què:
cada mètode té el seu «espai»: les seues variables moren quan acaba.
Detectar-ho:
«cannot find symbol».
Corregir-ho:
torna el valor amb return i guarda'l al main.

Canviar el paràmetre no canvia l'original

Què:
modifiques el paràmetre dins del mètode i fora res no canvia.
Per què:
el paràmetre és una CÒPIA del valor.
Detectar-ho:
el canvi «desapareix».
Corregir-ho:
torna el nou valor amb return.
6 · Resum visual

Idees que es queden

📦Mètode = tros de codi amb nom que pots reutilitzar.
📥Paràmetres: les dades que entren (en ordre!).
↩️return: el valor que torna… i acaba el mètode.
🖨️void: fa la faena però no torna res.
🏷️El tipus de la capçalera (int, double…) ha de coincidir amb el que tornes.
🧹El main queda curt i net: només organitza i crida.

Pregunta 01

Un mètode és…

Solució: C. Escriu la faena una volta i crida-la tantes com vullgues.
Pregunta 02

Què fa return dins d'un mètode?

Solució: A. Dona el resultat i el mètode s'acaba en eixe punt.
Pregunta 03

Un mètode void és un mètode que…

Solució: B. «Void» = buit de resultat: fa (imprimeix, saluda…) però no retorna res.
Pregunta 04

Què imprimeix?

public static int doble(int n) {
    return n * 2;
}
// al main:
System.out.println(doble(3) + 1);
Solució: D. doble(3) torna 6, i 6 + 1 = 7. El return es pot usar dins d'operacions.
Pregunta 05

Els paràmetres d'un mètode són…

Solució: B. Són les entrades de la màquina, i van en ordre.
Pregunta 06

Si un mètode diu que torna int però algun camí no té return…

Solució: C. Java és estricte: si promets un valor, tots els camins l'han de donar.
Pregunta 07

Una variable creada DINS d'un mètode…

Solució: A. Cada mètode té el seu espai; per a traure un valor fora, usa return.
Pregunta 08

Tens static double resta(double a, double b) { return a - b; }. Què dona resta(5, 12)?

Solució: B. 5 - 12 = -7. L'ordre dels paràmetres mana.
Pregunta 09

Per què dividim un programa en mètodes?

Solució: D. Menys repetició, més ordre i canvis més fàcils: escriu-ho una volta, usa-ho mil.
Pregunta 10

Què torna esParell(7)?

public static boolean esParell(int n) {
    return n % 2 == 0;
}
Solució: B. El residu de 7 entre 2 és 1, així que 7 % 2 == 0 és false. El mètode torna eixe false.
Exercici 1

Conversor de temperatura 🌡️

Mètode celsiusAFahrenheit(double c) (fórmula: c × 9/5 + 32). Demana una temperatura i mostra el resultat. Prova amb 0, 37 i 100.

Conversor.java
import java.util.Scanner;

public class Conversor {
    public static double celsiusAFahrenheit(double c) {
        return c * 9 / 5 + 32;
    }

    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        System.out.print("Graus Celsius: ");
        double c = tec.nextDouble();
        System.out.println(c + " °C són " + celsiusAFahrenheit(c) + " °F");
    }
}
Exercici 2

La nota en paraules

Mètode qualifica(double nota) que torne "Suspés", "Suficient", "Notable" o "Excel·lent" segons el valor. Mostra-ho per a les notes 3, 5.5, 7 i 9.5.

Qualifica.java
public class Qualifica {
    public static String qualifica(double nota) {
        if (nota < 5) {
            return "Suspés";
        } else if (nota < 7) {
            return "Suficient";
        } else if (nota < 9) {
            return "Notable";
        } else {
            return "Excel·lent";
        }
    }

    public static void main(String[] args) {
        double[] proves = {3, 5.5, 7, 9.5};
        for (int i = 0; i < proves.length; i++) {
            System.out.println(proves[i] + " → " + qualifica(proves[i]));
        }
    }
}
Exercici 3

Taula d'estrelles ⭐

Mètode void liniaEstrelles(int quantes) que imprimeixi tantes estrelles com li digues. Al main, fes un triangle de 5 files cridant-lo dins d'un bucle.

Triangle.java
public class Triangle {
    public static void liniaEstrelles(int quantes) {
        for (int i = 0; i < quantes; i++) {
            System.out.print("*");
        }
        System.out.println();
    }

    public static void main(String[] args) {
        for (int fila = 1; fila <= 5; fila++) {
            liniaEstrelles(fila);
        }
    }
}
Exercici 4

El màxim de tres 🥇

Escriu un mètode maxim3(int a, int b, int c) que torne el més gran dels tres. Prova'l des del main amb (3, 9, 5), (9, 3, 5) i (5, 9, 3) per a comprovar que funciona en totes les posicions.

Maxim.java
public class Maxim {
    public static int maxim3(int a, int b, int c) {
        int max = a;
        if (b > max) {
            max = b;
        }
        if (c > max) {
            max = c;
        }
        return max;
    }

    public static void main(String[] args) {
        System.out.println(maxim3(3, 9, 5));   // 9
        System.out.println(maxim3(9, 3, 5));   // 9
        System.out.println(maxim3(5, 9, 3));   // 9
    }
}
