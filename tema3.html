Repetir: els bucles

Els ordinadors no es cansen mai de repetir. Hui aprenem aprofitar eixe superpoder: comptar, acumular, demanar fins que estiga bé i jugar a endevinar números.

⏱ 3 hores 🔁 while i for 🧮 Comptadors i acumuladors ♾️ Bucles infinits (i com evitar-los)

Material creat per Agustín Gil - IES La vereda 2026 · Llicència CC BY-NC 4.0

1 · Introducció

Escriu «Hola» 1.000 vegades… a mà?

Si et demanara copiar «Hola» mil vegades en paper, et negaries (i amb raó). Però si ho fa un ordinador, tardarà mil·lisegons i ni es queixarà: repetir és el seu talent. Els bucles són la manera de dir-li «fes-ho altra volta, fins que jo diga».

2 · Què aprendrem?

Objectius del tema

  • Entendre per què necessitem bucles (i odiar copiar línies repetides).
  • Repetir amb while quan no sabem quantes voltes farem.
  • Repetir amb for quan sabem exactament quantes.
  • Comptar i acumular dins d'un bucle.
  • Detectar bucles infinits abans que es mengen l'ordinador.
3 · Teoria

Una idea, un exemple

3.1 · while: «mentre es complisca, altra volta»

Compte.java
int volta = 1;                 // el comptador comença en 1

while (volta <= 5) {           // mentre la condició siga certa…
    System.out.println("Volta número " + volta);
    volta++;                   // …i MOLT important: avancem
}
System.out.println("Fi! Hem fet " + (volta - 1) + " voltes");

Tres peces: inicialitzar la variable, comprovar la condició i actualitzar-la dins del bucle. Si oblides la tercera… benvingut al bucle infinit. ♾️

3.2 · for: el bucle amb cinturó de seguretat

El for junta les tres peces en una sola línia, perquè no se t'obliden:

Taulell.java
//  (inici; condició; actualització)
for (int i = 1; i <= 10; i++) {
    System.out.println(i + " vegades 7 són " + (i * 7));
}

3.3 · L'acumulador: la guardiola

Un acumulador és una variable-guardiola: comença a 0 i cada volta li cau algo dins.

Guardiola.java
int total = 0;                       // la guardiola buida

for (int dia = 1; dia <= 7; dia++) {
    total = total + 2;               // 2 € de paga al dia
}
System.out.println("En una setmana: " + total + " €");   // 14

3.4 · Repetir fins que estiga bé

Amb while podem demanar una dada fins que l'usuari la pose correcta: el bucle no para mentre la condició d'error es complisca.

Validacio.java
Scanner tec = new Scanner(System.in);
System.out.print("Posa una nota entre 0 i 10: ");
int nota = tec.nextInt();

while (nota < 0 || nota > 10) {      // mentre siga incorrecta…
    System.out.print("Eixa no val! Torna-ho a provar: ");
    nota = tec.nextInt();
}
System.out.println("Nota guardada: " + nota);

3.5 · for o while?

  • for quan saps quantes voltes: «de l'1 al 10», «10 intents».
  • while quan depén d'algo extern: «fins que encerte», «mentre el saldo done».
  • Els dos fan la mateixa faena; triem el que es llig millor.
4 · Programació guiada

Endevina el número 🎯

El clàssic dels clàssics: l'ordinador pensa un número de l'1 al 10 i tu l'has d'endevinar. El construïm a trossets.

1

Que pense un número

Random és una eina que dona números a l'atzar. La línia de baix pensa un enter de l'1 al 10. (De moment, copia-la tal qual; ja arribarem a entendre-la del tot.)

import java.util.Random;
// ...
Random atzar = new Random();
int secret = atzar.nextInt(10) + 1;   // 1..10
System.out.println("(Sssst… el número és " + secret + ")");
2

Primer intent

Demana un número a l'usuari i digues-li si ha encertat, amb un if.

System.out.print("Quin número pense? ");
int intent = tec.nextInt();
if (intent == secret) {
    System.out.println("Enhorabona!");
}
3

Pistes: més alt / més baix

Amplia l'if amb else if per a dir «més alt!» o «més baix!» quan falle.

if (intent == secret) {
    System.out.println("Enhorabona!");
} else if (intent < secret) {
    System.out.println("Més alt!");
} else {
    System.out.println("Més baix!");
}
4

El bucle que ho canvia tot

Embolicall-ho en un while (intent != secret): fins que no encerte, a seguir intentant. On has de posar la pregunta perquè es repetisca?

int intent = 0;
while (intent != secret) {
    System.out.print("Quin número pense? ");
    intent = tec.nextInt();
    // ací dins, els if de pistes
}
5

Comptem els intents

Afig un comptador de voltes i, en guanyar, mostra «L'has encertat en N intents».

int voltes = 0;
// dins del bucle: voltes++;
System.out.println("Encertat en " + voltes + " intents!");
5 · Errors habituals

Bucles que mosseguen

Bucle infinit ♾️

Què:
el programa no acaba mai d'imprimir.
Per què:
la variable de la condició mai canvia.
Detectar-ho:
eixida que no para; Ctrl+C per a matar-lo.
Corregir-ho:
comprova que dins del bucle la condició pot arribar a false.

El ; traïdor

Què:
while (i < 5); no fa res visible… i després el bloc s'executa una volta.
Per què:
el punt i coma tanca el bucle buit.
Detectar-ho:
el cos es fa una sola volta.
Corregir-ho:
mai ; just després de while/for.

Comptar de més o de menys

Què:
volies 10 voltes i en fa 9 (o 11).
Per què:
confusió entre < i <=, o començar en 0 vs 1.
Detectar-ho:
imprimeix la variable del bucle a cada volta.
Corregir-ho:
prova amb números xicotets i conta a mà.

Acumulador que no comença a 0

Què:
sumes «sobre» un valor que ja tenia algo.
Per què:
la guardiola no estava buida.
Detectar-ho:
resultats sempre desviats la mateixa quantitat.
Corregir-ho:
int total = 0; abans del bucle.
6 · Resum visual

Idees que es queden

🔁Bucle = repetir un bloc mentre la condició siga certa.
⏳while: no saps quantes voltes; for: sí que ho saps.
🧮Comptador conta voltes (i++).
🐷Acumulador guarda sumes (total += x), comença a 0.
🚪La condició d'eixida ha de poder complir-se sempre.
♾️Si no actualitzes la variable → bucle infinit.
🔍Per a depurar: imprimeix la variable del bucle a cada volta.
7 · Activitats

Tres sales d'entrenament

Mini exercicis (ràpids, a classe)

  1. Imprimeix de l'1 al 20 amb un for. Després, només els parells.
  2. Compte arrere des de 10 fins a 0 i «Enlairament! 🚀».
  3. Suma els números de l'1 al 100 amb un acumulador (pista: 5050).
  4. Demana 5 notes amb un bucle i mostra la suma (acumulador + comptador).
  5. Quantes voltes executa for (int i = 0; i < 5; i++)? I si comença en 1?
  6. Dibuixa un triangle de * de 5 files amb un bucle (pots imprimir "*".repeat(i)… o fer-lo amb bucles anidats si t'atreveixes).
Pregunta 01

Quin bucle triaries si NO saps quantes voltes s'ha de repetir?

Solució: B. «Mentre passe algo» = while; «exactament N voltes» = for.
Pregunta 02

Quantes voltes fa for (int i = 0; i < 4; i++) ?

Solució: C. i val 0, 1, 2 i 3 → quatre voltes. Amb <= en foren cinc.
Pregunta 03

i++ equival a…

Solució: A. Suma u i ho guarda a la variable: la forma curta d'avançar el comptador.
Pregunta 04

Què imprimeix este codi?

int suma = 0;
for (int i = 1; i <= 3; i++) {
    suma += i;
}
System.out.println(suma);
Solució: D. 1 + 2 + 3 = 6. La guardiola va acumulant a cada volta.
Pregunta 05

Un bucle infinit passa quan…

Solució: B. Si dins del bucle res canvia la condició, mai s'eixirà.
Pregunta 06

Abans d'entrar en un bucle que suma, l'acumulador ha de valdre…

Solució: A. La guardiola buida: int total = 0;, si no, la suma eixirà desviada.
Pregunta 07

Què imprimeix for (int i = 10; i > 0; i -= 3) System.out.print(i + " "); ?

Solució: C. 10, 7, 4, 1 — i quan val -2 la condició i > 0 ja és false, així que no s'imprimeix.
Pregunta 08

Si la condició d'un while ja és false abans de començar…

Solució: B. El while pregunta ANS d'entrar: si és false des del principi, ni una volta.
Pregunta 09

Volem demanar una nota fins que estiga entre 0 i 10. Quina condició manté el bucle actiu?

Solució: D. El bucle dura mentre la nota siga INCORRECTA; quan estiga bé, s'ix.
Pregunta 10

Quantes voltes fa este bucle?

int i = 0;
while (i < 10) {
    i += 2;
}
Solució: B. i val 0, 2, 4, 6 i 8: quan arriba a 10 la condició ja és false. Cinc voltes.
Exercici 1

La taula que tu digues

Demana un número i imprimeix la seua taula de multiplicar de l'1 al 10 amb un for.

Taula.java
import java.util.Scanner;

public class Taula {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        System.out.print("Taula del número: ");
        int num = tec.nextInt();

        for (int i = 1; i <= 10; i++) {
            System.out.println(num + " x " + i + " = " + (num * i));
        }
    }
}
Exercici 2

Sumadora fins al 0

Ves demanant números i acumulant-los fins que l'usuari escriga 0. Aleshores, mostra la suma total i quants números ha escrit.

Sumadora.java
import java.util.Scanner;

public class Sumadora {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        int total = 0, quantes = 0, num;

        System.out.print("Escriu un número (0 per a acabar): ");
        num = tec.nextInt();
        while (num != 0) {
            total += num;
            quantes++;
            System.out.print("Un altre: ");
            num = tec.nextInt();
        }
        System.out.println("Suma: " + total + " en " + quantes + " números");
    }
}
Exercici 3

Compte arrere personalitzat

Demana un número inicial i de quant en quant vol baixar (per exemple, de 3 en 3). Fes el compte arrere fins a 0 o menys, i acaba amb «Enlairament! 🚀».

Coet.java
import java.util.Scanner;

public class Coet {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        System.out.print("Des d'on comptem? ");
        int i = tec.nextInt();
        System.out.print("De quant en quant? ");
        int pas = tec.nextInt();

        for (; i > 0; i -= pas) {
            System.out.println(i + "...");
        }
        System.out.println("Enlairament! 🚀");
    }
}
Exercici 4

És primer? 🔢

Demana un número i digues si és primer (només divisible per 1 i per ell mateix). Recorre els divisors possibles amb un for i un %, i guarda el resultat en un boolean.

Primer.java
import java.util.Scanner;

public class Primer {
    public static void main(String[] args) {
        Scanner tec = new Scanner(System.in);
        System.out.print("Escriu un número: ");
        int n = tec.nextInt();

        boolean esPrimer = n > 1;
        for (int i = 2; i < n; i++) {
            if (n % i == 0) {
                esPrimer = false;
            }
        }

        if (esPrimer) {
            System.out.println(n + " és primer");
        } else {
            System.out.println(n + " no és primer");
        }
    }
}
Repte 1

🔑 Contrasenya amb 3 intents

La contrasenya és "java2026". L'usuari té 3 intents: si encerta, «Benvingut!»; si gasta els tres, «Blocat 🔒». Necessitaràs un comptador dins del while i un if per a saber com s'ha acabat.

🏀 Mitjana de punts del partit

Demana els punts que ha fet un jugador en cada quart (4 trimestres… vull dir, quarts 😄) fins que escriga -1 per a acabar. Mostra el total, quants quarts ha jugat i la mitjana de punts per quart.
